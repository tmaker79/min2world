# Milestone 14: 거점 건설 (개척자·건설자)

## 상태

완료

## 구현 결과

- 개척자·건설자를 이동력 2, 체력 100, 전투력·사거리 0인 City 전용 민간 유닛으로 추가하고 생산·유지비·할인 규칙을 연결했다. 맵별 누적 상한은 건설자 거점에만 적용한다.
- Village 정착과 Outpost·Farm·Mine·Blacksmith 건설을 공통 배치 판정에 연결했다. 개척자는 정착 시 소모되고 건설자는 비용만 지불한 뒤 새 거점에 남아 행동을 종료한다.
- 민간 유닛을 공격·반격·거점 공격·점령·통제 구역·AI 병력 상한에서 제외하되 이동·피격·적 통제 구역 영향은 유지했다.
- 사이드바 2단계 확인, 후보 타일 강조, `Esc` 취소, 군사/민간 생산 구역과 코드 기반 깃발·망치 아이콘을 추가했다.
- AI에 결정론적 정착·건설 후보 평가와 기존 건설자 재사용, 건설자 → 개척자 → 군사 생산 정책을 연결했다.
- 저장 스키마를 13으로 올리고 민간 유닛·`foundedBy`·신규 거점·타일 참조를 검증하며 스키마 12 저장 마이그레이션을 추가했다. 전체 336개 테스트와 린트·프로덕션 빌드가 통과한다.

## 목표

개척자는 정착 계열의 시작점인 Village를 세우고, 건설자는 군사·방어 계열의 Outpost와 생산 특화 시설인 Farm·Mine·Blacksmith를 건설한다. 상위 거점은 직접 건설하지 않고 Milestone 10의 발전 규칙으로 만든다.

## 의존

- Milestone 10 역할별 거점 발전(모든 신규 거점은 각 계열의 시작 단계)
- Milestone 13 AI 정책(확장 판단 연결)

## 포함 범위

### 개척자와 Village 건설

- `settler` 병종을 추가한다. 이동력 2, 최대 체력 100, 근접 전투력 0, 원거리 전투력 0, 사거리 0, 생산 비용 30으로 한다.
- 개척자는 City에서만 생산하며 기존 거점별 라운드당 1회 생산 제한을 공유한다.
- `siteSettled` 액션을 적용하면 개척자를 소모하고 해당 칸에 `kind: 'village'`인 새 `Site`를 생성한다. 개척자 생산 비용 30 외의 추가 자원은 소모하지 않는다.
- 새 Village는 `capitalFor` 값이 없는 일반 정착지이며, 수도 점령 기반 승리·패배 조건에 포함되지 않는다.

### 건설자와 군사·생산 거점 건설

- `builder` 병종을 추가한다. 이동력 2, 최대 체력 100, 근접 전투력 0, 원거리 전투력 0, 사거리 0, 생산 비용 15로 한다.
- 건설자는 City에서만 생산하며 기존 거점별 라운드당 1회 생산 제한을 공유한다.
- `siteConstructed` 액션은 `siteKind: 'outpost' | 'farm' | 'mine' | 'blacksmith'`를 받는다. 적용하면 건설 비용만 소모하고 해당 종류의 새 `Site`를 생성한다.

| 건설 거점 | `SiteType` | 건설 비용 | 역할 | 지형 조건 |
| --- | --- | ---: | --- | --- |
| 전초기지 | `outpost` | 10 | 군사·방어 계열 시작점 | 모든 통행 가능 육지 |
| 농장 | `farm` | 6 | 식량 생산 특화 | 평지 |
| 광산 | `mine` | 8 | 광물 생산 특화 | 언덕 또는 산에 인접한 통행 가능 육지 |
| 대장간 | `blacksmith` | 10 | 장비·생산 보조 특화 | 모든 통행 가능 육지 |

- 건설자는 거점을 완공해도 소모되지 않으며 새 거점 타일에 그대로 남는다. 건설 완료 시 `movementRemaining: 0`, `hasActed: true`로 만들어 해당 턴의 행동을 종료한다.
- 건설자별 건설 횟수나 충전량은 두지 않는다. 살아 있는 동안 다음 턴부터 비용을 지불하고 다른 합법 타일에 반복해서 건설할 수 있다.
- 새 Outpost·Farm·Mine·Blacksmith는 건설자 세력 소유로 즉시 생성되며 `capitalFor` 값이 없다.
- `town`과 `city`는 Village에서 발전하며 직접 건설하지 않는다. `keep`과 `stronghold`도 Outpost에서 발전한다.
- 건설 비용은 `siteConstructed` 적용 시 차감한다. 건설자 생산 비용 15는 영구 건설자를 확보하는 일회성 투자이며, 생산과 각 건설 단계 모두 행동 후 예상 유지비 예약액을 침범할 수 없다.
- 신규 거점의 기본 수입과 Blacksmith 효과는 Milestone 10의 기존 값을 그대로 사용한다. Blacksmith·Barracks의 생산비 할인은 군사 유닛에만 적용하며 개척자와 건설자 비용은 할인하지 않는다.

### 민간 유닛 공통 규칙

- `settler`와 `builder`는 민간 유닛이다. 공격·반격·거점 공격·거점 점령을 할 수 없고 통제 구역을 만들지 않는다.
- 민간 유닛은 적의 공격과 통제 구역 영향을 정상적으로 받으며 체력이 0이 되면 제거된다. 타일을 점유해 다른 유닛의 진입을 막는 규칙은 유지한다.
- 민간 유닛에는 병종 상성 공격 보너스를 적용하지 않는다. 피격 시 지형 방어와 체력 보정은 기존 규칙을 사용하되 반격 피해는 항상 0이다.
- 병종 목록을 `MILITARY_UNIT_TYPES = ['infantry', 'cavalry', 'archer', 'spearman']`, `CIVILIAN_UNIT_TYPES = ['settler', 'builder']`로 분리하고, 전체 순회가 필요한 곳에서만 두 목록을 합친 `UNIT_TYPES`를 사용한다.
- Outpost·Keep·Stronghold는 군사 유닛만 생산한다. City는 군사 유닛과 민간 유닛을 모두 생산한다.
- 생산된 민간 유닛은 기존 `unitProduced`의 결정론적 ID·이름·배치 규칙을 공유한다. `hp: 100`, `maxHp: 100`, `movementRemaining: 0`, `hasActed: true`로 생성해 생산한 턴에는 이동하거나 건설하지 못한다.

### 생성 데이터

- 건설 가능한 종류는 `BuildableSiteType = 'outpost' | 'farm' | 'mine' | 'blacksmith'`로 분리하고, 액션 형태는 다음과 같이 고정한다.

```ts
{ type: 'siteSettled'; unitId: string }
{ type: 'siteConstructed'; unitId: string; siteKind: BuildableSiteType }
```

- 두 액션은 진행 중인 게임에서 현재 세력 소유의 해당 민간 유닛이 행동 가능한 상태일 때만 유효하다. 유효하지 않은 액션은 자원·유닛·타일·거점을 변경하지 않는다.
- `Site`에 `foundedBy?: FactionId`를 추가해 거점을 최초로 생성한 세력과 세력별 누적 거점 생성 횟수를 저장한다. 기존 거점은 이 값이 없다.
- 개척자가 세운 Village와 건설자가 세운 군사·생산 거점 모두 `foundedBy`를 생성 세력으로 설정한다.
- 새 거점 ID는 `${factionId}-founded-${sequence}` 형식으로 가장 작은 미사용 양의 정수를 써서 결정론적으로 만든다.
- 새 거점 이름은 `${SITE_TYPE_LABELS[siteKind]} ${sequence}` 형식으로 만들고, `ownerId`와 위치는 민간 유닛의 세력과 현재 위치를 사용한다. `buildings`는 빈 배열, `constructionQueue`와 `capitalFor`와 `footprint`는 없음으로 시작한다.
- Farm·Mine·Blacksmith는 `level: 1`로 시작한다. Outpost는 `hp: 50`, `maxHp: 50`으로 시작하고 Village에는 체력 필드를 두지 않는다.
- 새 거점의 `lastDevelopedTurn`은 현재 턴으로 설정하고, 생산 가능한 Outpost의 `lastProducedTurn`도 현재 턴으로 설정해 건설 직후 같은 턴에 발전하거나 유닛을 생산하지 못하게 한다.
- 거점 생성 시 새 거점을 `sites`에 추가하고 해당 `Tile.siteId`를 같은 ID로 설정한다. 둘 중 하나만 변경되는 상태는 허용하지 않는다.
- `siteSettled` 적용이 성공하면 개척자 제거, 선택 상태 해제, 거점 추가, `Tile.siteId` 설정을 하나의 상태 전이에서 원자적으로 처리한다.
- `siteConstructed` 적용이 성공하면 건설 비용 차감, 건설자의 이동력·행동 상태 갱신, 선택 상태 해제, 거점 추가, `Tile.siteId` 설정을 하나의 상태 전이에서 원자적으로 처리한다. 건설자는 유닛 목록에서 제거하지 않는다.

### 배치 규칙

- 개척자와 건설자는 자신이 있는 타일에만 거점을 세울 수 있다.
- 개척자는 통행 가능 육지에만 Village를 세울 수 있다. 물·산·기존 거점 타일은 거부한다.
- 새 Village는 모든 기존 거점과의 육각 거리가 4 이상이어야 한다.
- 건설자는 표의 지형 조건을 만족하는 타일에만 해당 군사·생산 거점을 세울 수 있다.
- 새 Outpost·Farm·Mine·Blacksmith는 모든 기존 거점과의 육각 거리가 2 이상이어야 한다.
- 건설자 거점은 건설자 세력이 소유한 Town·City·Keep·Stronghold에서 통행 가능 육지 그래프 거리 3 이내에만 건설할 수 있다. 이 거리는 유닛·통제 구역을 무시하고 물·산을 경로에서 제외한다. 적 거점과 중립 거점은 이 연결 기준에 포함하지 않는다.
- 타일 소유권 모델은 없으므로 자기 영토나 아군 인접 조건은 요구하지 않는다.
- 맵 가장자리에도 정착할 수 있으며 수도는 기존 거점 거리 제한으로 보호한다.
- 개척자의 생산 수와 누적 Village 건설 수에는 상한을 두지 않는다.
- 세력별 누적 건설자 거점 상한은 2인용 2, 초소형 4, 소형 10, 중형 24다. Outpost·Farm·Mine·Blacksmith를 합산하고 `foundedBy`를 기준으로 누적 횟수를 계산한다.
- 실제 건설 가능 여부는 `foundedBy` 기준 누적 횟수가 상한보다 작은지 검사한다. 살아 있는 민간 유닛 수는 건설 가능 여부를 제한하지 않는다.
- 개척자는 이미 생성한 Village 수나 현재 생존한 개척자 수와 관계없이 생산할 수 있다.
- 소모되지 않는 건설자는 `누적 건설자 거점 생성 수 < 누적 건설자 거점 상한`일 때 생산할 수 있다. 생존 건설자 수는 플레이어의 생산 가능 여부를 제한하지 않으며 별도의 동시 보유 상한도 없다.

### 경제

- 신규 Village와 Outpost는 각 발전 계열의 첫 단계, 신규 Farm·Mine·Blacksmith는 생산 특화 시설 1레벨로 시작한다.
- 신규 거점은 Milestone 10과 같은 발전·개발 규칙을 사용한다.
- Village는 Town과 City로, Outpost는 Keep과 Stronghold로만 발전한다. 생산 특화 시설은 다른 종류로 승급하지 않는다.
- 신규 거점은 기존 점령 규칙의 대상이며, 점령되어도 `foundedBy`는 변하지 않는다.
- 개척자와 건설자의 유지비는 각각 1이며, Milestone 13의 병력 상한에는 포함하지 않는다.
- 정착 성공으로 개척자가 제거되면 해당 유지비 1도 즉시 사라진다. 건설자는 건설 후에도 유지되므로 `siteConstructed`의 예약액 검사에 유지비 감소를 반영하지 않으며 이후 턴에도 유지비 1을 계속 지불한다.
- 개척자와 건설자의 동시 보유 수에는 별도 상한을 두지 않는다.

### UI

- 개척자 선택 시 정착 가능 칸을 하이라이트하고 `Village 건설` 버튼을 표시한다.
- 건설자 선택 시 `Outpost` / `Farm` / `Mine` / `Blacksmith` 중 하나를 고르는 건설 메뉴를 표시하고, 종류를 고르면 현재 타일의 건설 가능 여부와 비용을 보여 준다.
- Village는 개척자 소모를 알리는 확인 후에만 건설한다. 군사·생산 거점은 건설자가 살아남아 해당 턴 행동을 종료한다는 점과 건설 비용 차감을 알리는 확인 후에만 건설한다.
- 유닛 상세와 생산 UI에서 개척자·건설자는 `비전투`로 표시하고, 공격력이나 `사거리 1`처럼 실제로 사용할 수 없는 전투 정보는 표시하지 않는다.
- City 생산 목록을 군사 유닛과 민간 유닛 구역으로 나누고 민간 유닛 구역에 개척자와 건설자를 추가한다. 다른 거점의 생산 목록에는 민간 유닛을 노출하지 않는다.
- 생산 비용·유지비 예약액·거점의 이번 턴 생산 여부 외에 남은 건설 가능량도 생산 버튼 활성 조건에 포함한다. 개척자에는 수량·누적 건설 상한을 적용하지 않고, 건설자만 누적 건설자 거점 상한 도달 여부를 검사한다.

### AI

- AI의 공격·전략 이동 후보와 병력 상한 계산에서 민간 유닛을 제외한다. 민간 유닛은 전용 후보 탐색으로만 행동하며 유효한 건설 행동이 있으면 이동보다 먼저 실행한다.
- 개척 후보는 가장 가까운 적 수도까지의 가중 경로 비용 → 개척자에서 후보까지의 가중 경로 비용 → `r` → `q` 오름차순으로 고른다.
- 건설 후보 종류의 우선순위는 다음 순위값의 오름차순으로 고정한다.
  1. 적 군사 유닛 또는 적 요새화 거점에서 육각 거리 3 이내인 전초기지 후보
  2. 광산 후보
  3. 농장 후보
  4. 대장간 후보
  5. 위 전선 조건에 해당하지 않는 전초기지 후보
- 같은 우선순위의 건설 후보는 건설자에서 후보까지의 가중 경로 비용 → 가장 가까운 아군 상위 거점과의 그래프 거리 → `r` → `q` 오름차순으로 고른다. 생산 필요 판단에서는 건설자 위치 대신 생산 City의 모든 합법 배치 칸 중 최소 가중 경로 비용을 사용한다.
- 민간 유닛이 선택한 후보 타일에 없으면 기존 가중 최단 경로를 따라 이동한다. 민간 유닛은 적 통제 구역의 이동 제약과 비용을 받으며, 도달 가능한 후보가 없으면 대기한다.
- 후보 타일에 도착했지만 건설 비용과 유지비 예약액 조건을 충족하지 못하면 자원을 음수로 만들지 않고 대기한다. 다음 자기 턴에 같은 결정론적 규칙으로 다시 평가한다.
- AI는 모든 기존 유닛 행동과 경제 투자 후, 군사 유닛 생산 전에 건설자 → 개척자 순서로 생산 필요를 판단한다.
- 도달 가능한 건설 후보가 있고 누적 건설자 거점 상한에 도달하지 않았더라도, 현재 생존한 건설자 중 하나라도 합법 후보에 도달할 수 있으면 AI는 건설자를 추가 생산하지 않는다.
- 합법 후보에 도달 가능한 생존 건설자가 없고, 건설자 생산 비용 15와 선택한 후보의 건설 비용을 지불한 뒤에도 유지비 예약액을 남길 수 있을 때만 AI가 건설자를 생산한다.
- 도달 가능한 개척 후보가 있고 개척자 생산 비용 30을 지불한 뒤에도 유지비 예약액을 남길 수 있을 때 개척자를 생산한다. AI는 이미 생존 개척자가 있으면 먼저 그 개척자를 활용한다.
- 한 City가 건설자 또는 개척자를 생산하면 기존 라운드당 1회 생산 제한에 따라 같은 턴에 다른 유닛을 추가 생산하지 않는다.

## 구현 순서

1. 개척자·건설자 타입, 군사·민간 병종 목록, 생산·유지비·할인 제외 규칙을 추가한다.
2. 공격·반격·통제 구역·점령·병력 상한에서 민간 유닛을 구분하고 City 전용 생산 및 남은 건설 가능량 검사를 중앙 규칙으로 만든다.
3. Village 건설과 군사·생산 거점 건설 액션, 비용, 생성 기본값, 건설자의 존속·행동 종료, 지형·거리·연결·상한 규칙을 추가한다.
4. 맵 하이라이트·건설 메뉴·확인 UI와 City의 군사·민간 생산 구역을 연결한다.
5. AI의 결정론적 정착 확장과 군사·생산 거점 건설 정책을 연결한다.
6. 스키마를 13으로 올리고 `foundedBy`·민간 유닛·새 거점·`Tile.siteId` 참조 무결성 검증을 추가한다. 스키마 12 저장의 기존 거점은 `foundedBy` 없음으로 마이그레이션한다.

## 제외 범위

- 상위 거점 직접 건설
- 건설자별 작업 횟수·충전량·내구도 제한
- 도로·무역로·거점 사이 수입 연결
- 동맹
- 보급망 본격화(Milestone 15)

## 완료 조건

- 플레이어와 AI가 개척자로 새 Village를, 건설자로 Outpost·Farm·Mine·Blacksmith를 세울 수 있다.
- 개척자로 Village를 세우면 개척자는 소모된다. 건설자로 군사·생산 거점을 세우면 거점별 건설 비용만 소모되고 건설자는 새 거점 타일에 남은 채 해당 턴 행동을 종료한다.
- 거점 종류별 지형·최소 거리·아군 상위 거점 연결 제약이 강제된다.
- 신규 거점은 수도가 아니며 기존 승리·패배 조건을 바꾸지 않는다.
- 플레이어와 AI 모두 개척자·Village 상한 없이 확장할 수 있으며, 맵 크기별 누적 건설자 거점 상한은 준수한다.
- 개척자와 건설자는 City에서만 생산되고 군사 생산비 할인을 받지 않는다. 개척자와 Village에는 누적 상한이 없고, 건설자는 누적 건설자 거점 상한을 준수한다.
- 개척자와 건설자는 공격·반격·통제 구역·거점 점령을 하지 않지만 적의 공격과 통제 구역 영향을 받고 타일은 정상적으로 점유한다.
- AI는 같은 상태에서 같은 거점 종류와 타일을 고르며, 건설자·개척자·군사 유닛 생산 순서와 유지비 예약액을 지킨다.
- 새로 생성한 거점을 저장·불러오기해도 소유권·생성 세력·타일 참조가 유지된다.
- 규칙·리듀서·AI·저장 마이그레이션·UI 테스트와 린트·빌드가 통과한다.
