# Milestone 04: 저장과 불러오기

## 상태

다음 목표

## 목표

진행 중인 게임을 브라우저에 저장하고 나중에 같은 상태에서 이어서 플레이할 수 있게 한다.

## 포함 범위

- `localStorage` 기반 단일 저장 슬롯
- 현재 게임 수동 저장, 불러오기와 저장 데이터 삭제
- 저장 시각과 `schemaVersion`을 포함한 JSON 저장 형식
- 불러오기 전 필수 필드, 값 범위와 참조 무결성 검사
- 손상되거나 지원하지 않는 저장 데이터에 대한 오류 안내
- 저장 성공 여부와 저장 시각을 보여 주는 UI
- 저장·불러오기·삭제와 오류 처리 테스트

## 기본 정책

- 저장은 플레이어 턴의 전투 모션이 없는 상태에서만 허용한다.
- AI 턴과 승리·패배 결과 화면에서는 저장할 수 없다.
- `GameState`만 저장하며 선택 강조, 전투 모션, AI 타이머와 접근성 알림 같은 일시적 UI 상태는 저장하지 않는다.
- 불러오기는 검증에 성공한 상태만 `gameLoaded` action으로 reducer에 전달한다.
- 잘못된 저장 데이터는 현재 게임 상태를 변경하지 않는다.
- 현재 스키마와 호환되지 않는 저장은 자동 추측 변환하지 않고 지원하지 않는 버전으로 안내한다.

## 제외 범위

- 여러 저장 슬롯
- 자동 저장
- 파일 내보내기와 가져오기
- 서버 및 클라우드 저장
- 계정 간 저장 공유

## 완료 조건

- 새로고침하거나 브라우저를 다시 열어도 저장한 턴·유닛·체력·도시 소유권에서 게임을 계속할 수 있다.
- 손상된 데이터와 다른 스키마 버전이 게임을 중단시키거나 현재 상태를 덮어쓰지 않는다.
- 저장, 불러오기, 삭제와 UI 흐름이 테스트되며 전체 검증 명령을 통과한다.
