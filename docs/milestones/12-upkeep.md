# Milestone 12: 유지비

> 이 문서는 해당 마일스톤 완료 당시의 기록이다. 현재 규칙은 [게임 가이드](../game-guide.md), 전체 진행 상태는 [개발 마일스톤](README.md)을 따른다.

## 상태

완료

## 목표

유닛에 턴 유지비를 도입해 병력 과잉을 자원 적자로 억제한다. 적자에서 벗어날 수 있게 자발적 해산은 제공하되, 탈영·강제 해산은 넣지 않는다.

## 의존

- Milestone 05 수입 정산
- Milestone 11 건물 수입

## 포함 범위

### 규칙

| 대상 | 유지비/턴 |
| --- | ---: |
| 보병 | 1 |
| 창병 | 1 |
| 궁병 | 1 |
| 기병 | 2 |

- 건물 유지비는 이번 마일스톤에서 0으로 고정한다.
- 세력 턴 종료 정산은 기존 수입 지급 시점에 한 번에 처리한다.
  `다음 자원 = max(0, 현재 자원 + 거점·건물 수입 - 유닛 유지비)`
- `순수입 = 거점·건물 수입 - 유닛 유지비`이고, `순수입 < 0`이면 **적자 상태**로 표시한다.
- `다음 유지비 예약액 = max(0, 유지비 - 수입)`으로 계산한다.
- 생산·레벨업·건설 시작은 비용 차감 후 자원이 다음 유지비 예약액 이상일 때만 허용한다. 적자라도 비축한 자원으로 다음 정산을 감당할 수 있으면 행동을 완전히 막지 않는다.
- 유지비를 다 내지 못해도 유닛 삭제·체력 감소·사기 패널티는 자동 발생하지 않는다.

### 자발적 해산

- 활성 세력은 자신의 턴에 소유 유닛을 `unitDisbanded` 액션으로 해산할 수 있다.
- 해산은 확인 후 즉시 적용하며 자원을 환불하지 않는다.
- AI는 유지비가 수입보다 크면 어떤 투자도 하기 전에 유닛을 하나 해산하고 최신 상태에서 다시 판단한다. 적자가 해소될 때까지 이 결정을 유닛 수 이내에서 반복할 수 있다.
- AI 해산 우선순위는 유지비가 높은 유닛 → 체력이 낮은 유닛 → ID 오름차순이다. 인접한 적을 공격할 수 있는 유닛은 다른 후보가 있으면 해산하지 않는다.

### UI

- 상태바에 `수입 / 유지비 / 순수입`을 표시한다.
- 적자일 때 다음 유지비 예약액과 생산·개발·건설 버튼 비활성 사유
- 부대 정보창의 `해산` 버튼과 확인 흐름

### AI

- 다음 유지비 예약액을 남기지 못하면 생산·건설·레벨업을 하지 않는다.
- 유지비가 수입보다 큰 동안 위 우선순위로 하나씩 해산하고 매번 재평가한다.

## 구현 순서

1. 유지비 테이블과 순수입 계산 함수를 추가한다.
2. 턴 정산과 생산/개발/건설 가능 조건에 연결한다.
3. UI 요약과 적자 안내를 넣는다.
4. 테스트를 추가한다.

## 제외 범위

- 보급망(Milestone 15)
- 사기·탈영(Milestone 15)
- 탈영·자동 강제 해산

## 완료 조건

- 턴마다 유지비가 반영되고 확장 행동이 다음 유지비 예약액을 침범하지 않는다.
- 자원이 음수가 되지 않는다.
- 플레이어와 AI가 유닛을 자발적으로 해산해 지속적인 적자에서 벗어날 수 있다.
- 관련 테스트와 빌드가 통과한다.

## 구현 결과

- 병종별 유지비와 세력별 수입·유지비·순수입·예약액을 저장하지 않는 파생 경제 정보로 구현했다.
- 생산은 신규 유닛 유지비, 발전은 발전 후 증가한 거점 수입을 예상 상태에 즉시 반영한다. 건설 중인 건물 효과는 완공 전까지 예약 계산에 포함하지 않는다.
- 턴 종료 정산은 자원 0을 하한으로 적용하며 부채·피해·강제 해산은 발생시키지 않는다.
- 플레이어 해산의 활성 턴·소유권·무환불·선택 해제와 확인 UI를 구현했다.
- AI는 다른 행동보다 적자 해소를 먼저 처리하며, 고유지비·저체력·ID 순으로 반복 해산하고 가능한 경우 즉시 공격 가능한 부대를 보존한다.
- 상태바와 생산·발전·건설 UI에 유지비 예약액 및 구분된 차단 사유를 표시한다.
- 파생 정보만 추가해 저장 스키마는 12를 유지한다.
