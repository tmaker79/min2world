# Milestone 07: 메인 UI 재구성

## 상태

진행 중

## 목표

육각 지도·seed·생산·저장이 늘어난 뒤에도 한 화면에서 지도가 주인공이 되게 한다. 규칙과 상태 로직은 바꾸지 않고 레이아웃·정보 구조·문서만 손본다.

## 현재 문제

- 큰 헤더와 보드 안의 seed 폼이 플레이 중에도 맵 위를 차지한다.
- 우측 패널에 부대 정보·생산·저장·범례·도움말이 한꺼번에 쌓여 세로 스크롤이 길다.
- 10×10 사각 지도용 셸 폭과 여백이 12×12 육각 지도에 비해 맵 영역을 부족하게 만든다.

## 포함 범위

### 상단 크롬

- 큰 미션 헤더를 compact brand bar로 축소
- seed 입력·seed로 새 게임·무작위 지도를 `새 게임` 드롭다운/패널로 이동
- 현재 seed를 상단에 작게 표시

### 우측 context rail

- 상단 고정: 부대 정보, 부대 생산
- 하단 탭: 범례 / 저장 / 도움말
- 탭은 한 패널만 보이게 하고 `aria-selected`와 키보드 전환을 지원

### 맵 우선 레이아웃

- 셸 폭·패딩 조정과 `game-layout` 비율을 맵 쪽으로 확대
- board 패널 여백을 줄여 육각 지도가 더 많은 화면을 사용
- 기존 타일·유닛 토큰·색 변수는 유지

### 문서와 테스트

- 조작 안내를 새 UI 위치에 맞게 갱신
- seed·생산·승리 UI 테스트를 새 DOM/라벨에 맞게 수정

## 확정 정보 구조

```text
┌─ app-chrome ─────────────────────────────────────────┐
│ brand  ·  현재 seed  ·  [새 게임 ▾]  ·  [저장]       │
├─ status-bar ─────────────────────────────────────────┤
│ 턴 · 세력 · 자원 · 턴 종료                           │
├─ board (넓게) ──────────────┬─ context-rail ─────────┤
│ 육각 지도                   │ 부대 정보              │
│ (결과 오버레이 유지)        │ 부대 생산              │
│                             │ 탭: 범례 | 저장 | 도움 │
└─────────────────────────────┴────────────────────────┘
```

- 플레이 축: 지도 + 상태바 + 부대 정보/생산
- 메타 축: seed·새 게임은 상단 드롭다운, 저장/범례/도움말은 우측 탭
- 도움말: 짧은 요지로 축소하고 상세는 README에 둔다

## 구현 순서

1. 상단 brand bar와 `새 게임` 드롭다운으로 seed 조작을 보드 밖으로 옮긴다.
2. 우측을 정보/생산 + 범례|저장|도움말 탭으로 재구성한다.
3. 맵 우선 폭·여백·반응형 레이아웃을 조정한다.
4. README와 UI 테스트를 새 위치에 맞추고 빌드를 확인한다.

## 제외 범위

- 게임 규칙, 저장 스키마, 맵 생성기 변경
- PixiJS 렌더러와 카메라 줌·팬 시스템
- 모바일 전용 재설계 (기존 브레이크포인트만 맞춤)

## 완료 조건

- 플레이 중 첫 시선이 육각 지도이고, seed/저장이 맵을 가리지 않는다.
- 부대 선택·이동·생산·턴 종료·승패가 기존과 동일하게 동작한다.
- 범례/저장/도움말은 탭으로 전환되며 동시에 전부 펼쳐지지 않는다.
- 관련 UI 테스트와 빌드가 통과한다.
