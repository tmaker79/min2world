# Milestone 07: 메인 UI 재구성

## 상태

완료

## 목표

육각 지도·seed·생산·저장이 늘어난 뒤에도 한 화면에서 지도가 주인공이 되게 한다. 규칙과 상태 로직은 바꾸지 않고 레이아웃·정보 구조·문서만 손본다.

## 시작 시점의 문제

- 큰 헤더와 보드 안의 seed 폼이 플레이 중에도 맵 위를 차지했다.
- 우측 패널에 부대 정보·생산·저장·범례·도움말이 한꺼번에 쌓여 세로 스크롤이 길었다.
- 10×10 사각 지도용 셸 폭과 여백이 12×12 육각 지도에 비해 맵 영역을 부족하게 만들었다.

## 포함 범위

### 상단 크롬

- compact brand bar (`min2world`)
- 현재 seed 표시
- `새 게임` · `범례` · `저장` · `도움말` 메뉴 (한 번에 하나만 팝오버)
- 바깥 클릭과 `Esc`로 메뉴 닫기

### 지도 프레임 (board-panel)

- 제목(전략 지도)과 HEX 수
- `StatusBar`(턴·세력·자원·턴 종료)를 보드 안, 헥스 위에 배치
- 육각 지도와 승패 오버레이
- 유닛 타일 호버 시 요약 툴팁

### 우측 사이드

- 부대 정보
- 부대 생산
- 메타 패널(범례·저장·도움말)은 두지 않음

### 맵 우선 레이아웃

- 셸 폭·패딩 조정과 `game-layout` 비율을 맵 쪽으로 확대
- 지도를 보드 스크롤 영역에서 가운데 정렬
- 기존 타일·유닛 토큰·색 변수는 유지

### 문서와 테스트

- 조작 안내를 상단 메뉴·보드 안 상태바에 맞게 갱신
- seed·생산·승리·상단 메뉴 UI 테스트 반영

## 확정 정보 구조

```text
┌─ app-chrome ──────────────────────────────────────────────┐
│ min2world · seed · [새 게임] [범례] [저장] [도움말]        │
└───────────────────────────────────────────────────────────┘
┌─ board-panel ────────────────────┬─ side-panel ───────────┐
│ 전략 지도 · 144 HEX              │ 부대 정보              │
│ status-bar (턴·세력·자원·종료)   │ 부대 생산              │
│ 육각 지도 (호버 툴팁)            │                        │
│ (결과 오버레이 유지)             │                        │
└──────────────────────────────────┴────────────────────────┘
```

- 플레이 축: 지도 + 보드 안 상태바 + 부대 정보/생산
- 메타 축: seed·새 게임·범례·저장·도움말은 상단 팝오버
- 도움말: 짧은 요지로 축소하고 상세는 README에 둔다

## 구현 순서

1. 상단 brand bar와 `새 게임` 드롭다운으로 seed 조작을 보드 밖으로 옮긴다.
2. 맵 우선 폭·여백·반응형 레이아웃을 조정한다.
3. `StatusBar`를 board-panel 안으로 옮긴다.
4. 범례·저장·도움말을 상단 메뉴 팝오버로 옮기고 우측 탭을 제거한다.
5. README와 UI 테스트를 새 위치에 맞춘다.

## 제외 범위

- 게임 규칙, 저장 스키마, 맵 생성기 변경
- PixiJS 렌더러와 카메라 줌·팬 시스템
- 모바일 전용 재설계 (기존 브레이크포인트만 맞춤)

## 완료 조건

- 플레이 중 첫 시선이 육각 지도이고, seed/메타 메뉴가 맵을 상시 가리지 않는다.
- 부대 선택·이동·생산·턴 종료·승패가 기존과 동일하게 동작한다.
- 범례/저장/도움말/새 게임은 상단에서 한 메뉴만 열린다.
- 관련 UI 테스트와 빌드가 통과한다.

## 구현 결과

- `AppChrome`과 공유 `openChromeMenu`로 새 게임·범례·저장·도움말 팝오버를 상단에 두었다.
- `StatusBar`는 board-panel 안(제목 아래, 헥스 위)에 배치했다.
- 우측은 `InfoPanel`과 `ProductionPanel`만 남기고 `ContextTabs`는 제거했다.
- 유닛 호버 요약 툴팁을 지도 오버레이로 표시한다.
- 셸 폭을 넓히고 지도를 가운데 정렬해 육각 지도 영역을 키웠다.
- README·UI 테스트를 상단 메뉴 기준으로 맞췄다.
