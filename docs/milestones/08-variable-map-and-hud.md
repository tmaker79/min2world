# Milestone 08: 가변 지도·다세력·HUD 조작

## 상태

완료

## 목표

고정 12×12·2세력 전제를 넘어, 맵 크기와 세력 수를 선택하고 지도 조작·HUD를 플레이에 맞게 다듬는다.

## 포함 범위

### 시작 설정

- 시작 화면에서 맵 크기·세력 수(2~4)·내 세력·seed 선택
- 맵 프리셋: 초소형 15×10(듀얼 전용), 소형 21×14, 표준 42×28, 대형 84×56
- 세력 ID `f1`~`f4`, `humanFactionId`, `factionOrder`

### 지도 조작

- 마우스 휠 줌(커서 기준 스크롤 보정)
- 드래그 팬, 미니맵 시점 이동
- 초소형·소형은 한 화면에 맞추는 레이아웃

### HUD와 입력

- 지형 호버 툴팁(좌표·이동·전투 보정·거점)
- 유닛 호버 툴팁(병종·체력·전투력·이동, 상태 없음)
- 좌클릭: 유닛/성 선택, 공격, 생산 배치
- 우클릭: 이동 가능 칸으로 이동
- 성 클릭 시 성 정보창. 위부터 생산 목록 → 생산/건설 메뉴 → 성 정보
- 유닛 정보창을 성 정보창과 같은 카드 스타일로 통일
- 필요할 때만 HUD 표시(선택·성·생산 중)

### 저장

- `schemaVersion` 7, `mapGenerationVersion` 5
- 스키마 6(`player`/`enemy`) 저장은 `f1`/`f2`로 마이그레이션

## 제외 범위

- 건설 시스템 구현(메뉴만 비활성 표시)
- AI 난이도·외교·전장의 안개
- PixiJS 렌더러

## 완료 조건

- 시작 화면 설정으로 선택한 맵·세력 구성이 게임에 반영된다.
- 우클릭 이동과 좌클릭 선택/공격이 충돌하지 않는다.
- 성·유닛 정보창과 툴팁이 현재 UI 규칙대로 동작한다.
- 관련 테스트와 빌드가 통과한다.

## 구현 결과

- `StartScreen`, `BOARD_SIZE_PRESETS`, 다세력 맵 생성·승패·AI·저장을 연결했다.
- `useMapZoom` / `useMapPan`과 미니맵 줌 연동을 추가했다.
- `CityPanel`·`InfoPanel`·지형/유닛 툴팁·우클릭 이동을 반영했다.
- README와 개발 계획을 현재 조작·스키마에 맞게 갱신했다.
