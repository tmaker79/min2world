# Milestone 09: 지형 확장 (사막, 툰드라)

> 이 문서는 해당 마일스톤 완료 당시의 기록이다. 현재 규칙은 [게임 가이드](../game-guide.md), 전체 진행 상태는 [개발 마일스톤](README.md)을 따른다.

## 상태

완료

## 목표

맵 생성기에 사막과 툰드라를 추가해 기후 대비를 만들고, 이동·표시·저장까지 기존 지형과 동일한 경로로 통합한다.

## 의존

- Milestone 06의 고도·습도 기반 지형 생성
- Milestone 08의 가변 맵·지형 툴팁·범례

## 포함 범위

### 규칙

| 지형 | 이동 비용 | 전투 보정 | 비고 |
| --- | ---: | ---: | --- |
| 사막 | 2 | 0 | 저습도·고온(저위도/저고도) 영역 |
| 툰드라 | 2 | 0 | 고위도 또는 저온 영역 |

- 특수 피해, 보급 페널티, 오아시스는 넣지 않는다.
- 산·물과 같이 통과 불가는 아니다.

### 맵 생성

- 기존 elevation·moisture에 **온도** 축을 추가한다.
- 온도는 보드 높이를 0~1로 정규화한 위도와 seed 기반 저빈도 노이즈에 고도에 따른 냉각 보정을 더해 계산한다. 보드 크기가 달라져도 기후 비율은 같은 기준을 쓴다.
- 사막: 습도 낮고 온도 높은 열린 지형
- 툰드라: 온도 낮은 열린 지형
- 수도와 시작 유닛에서 육각 거리 2 이내의 통행 가능 타일은 평지·언덕·숲을 우선해 초반 이동 영역을 보장한다.
- `MAP_GENERATION_VERSION`은 5에서 6으로 올린다. 같은 seed라도 버전 5와 6의 지도는 다를 수 있다.

### UI·저장

- 사막·툰드라는 기존 타일 렌더링에 CSS 색면으로 표시한다. 이번 마일스톤에서 신규 래스터 에셋은 추가하지 않는다.
- 미니맵 색, 범례, 지형 툴팁 라벨을 같이 추가한다.
- `Terrain` 유니온·저장 검증·스키마 검증에 `desert` / `tundra` 추가
- `schemaVersion` 7은 유지하고 `mapGenerationVersion` 5·6을 모두 지원한다. 버전 5 저장은 저장된 타일을 그대로 불러오며 재생성하지 않는다.
- 불러온 버전 5 지도는 그 버전을 유지한 채 다시 저장할 수 있게 `SUPPORTED_MAP_GENERATION_VERSIONS`를 저장 검증에도 공통 적용한다.

## 구현 순서

1. 타입·이동·전투 테이블·라벨에 사막/툰드라를 추가한다.
2. 생성기에 온도/위도 축과 지형 분기, 수도 주변 보호를 넣는다.
3. 렌더·미니맵·범례·툴팁을 연결한다.
4. 생성·이동·저장 검증 테스트와 README 지형 표를 갱신한다.

## 제외 범위

- 사막/툰드라 전용 병종·건물
- 턴마다 체력 피해
- 보급 거리 보정(Milestone 15)

## 완료 조건

- 새 지형이 생성·표시되고 이동 비용 2로 통행된다.
- 수도 주변이 고립되지 않는다.
- 같은 seed + 새 `mapGenerationVersion`은 결정론적으로 재현된다.
- 버전 5·스키마 7 저장은 기존 지도를 바꾸지 않고 불러오기·재저장된다.
- 관련 테스트와 빌드가 통과한다.

## 완료 이후 확장

초기 명세의 사막·툰드라 통합을 완료한 뒤, 지형 표현과 생성 규칙을 다음과 같이 확장했다. 위 포함·제외 범위는 Milestone 09 착수 당시의 기준으로 보존한다.

- 현재 `Terrain`은 평지·언덕·숲·산·물·사막·사막 언덕·오아시스·툰드라·툰드라 숲·툰드라 산의 11종이다.
- 오아시스는 덥고 건조한 평지의 5%를 후보로 삼고, 인접 6칸이 모두 사막 또는 사막 언덕이며 다른 오아시스와 인접하지 않은 경우에만 유지한다.
- 사막 언덕과 툰드라 숲은 전투력 보정 +3을 제공하고, 툰드라 산은 통과할 수 없다.
- 사막·툰드라 계열과 오아시스에 전용 래스터 타일을 연결했다.
- 일반 숲은 연결된 군락마다 활엽수 또는 침엽수 변형을 사용한다.
- 현재 저장 스키마는 8, 맵 생성 버전은 20이며 맵 생성 버전 5부터 20까지 저장된 타일을 그대로 지원한다.
