# Milestone 01: 지도와 유닛 이동

> 이 문서는 해당 마일스톤 완료 당시의 기록이다. 현재 규칙은 [게임 가이드](../game-guide.md), 전체 진행 상태는 [개발 마일스톤](README.md)을 따른다.

## 상태

완료

## 목표

10×10 지도에서 플레이어 유닛을 선택하고, 이동 가능한 칸을 확인해 이동한 뒤 턴을 종료할 수 있는 첫 번째 플레이 흐름을 구현한다.

## 구현 결과

- Vite, React와 TypeScript 프로젝트 기반
- React와 CSS Grid로 렌더링하는 10×10 지도
- 평지, 산, 물의 지형 3종
- 플레이어와 적 세력의 도시 및 유닛 배치
- 보병과 기병의 서로 다른 이동력
- 상하좌우 가중치 이동 범위 계산
- 물, 점유 타일과 지도 경계를 고려한 이동 제한
- 유닛 선택, 이동 가능 타일 표시와 정보 패널
- 이동 후 행동 완료 및 턴 종료 시 행동 초기화
- 데스크톱 우선 반응형 전략 보드게임 UI

## 확정된 규칙

- 평지 이동 비용은 1, 산은 2이며 물은 통행할 수 없다.
- 보병의 이동력은 2, 기병은 3이다.
- 유닛은 상하좌우로만 이동한다.
- 다른 유닛이 점유한 타일은 통과하거나 도착할 수 없다.
- 유닛은 한 턴에 한 번 행동하고 턴 종료 시 다시 행동할 수 있다.
- 적 세력은 지도에 표시되지만 아직 행동하지 않는다.

## 검증 결과

- 규칙, reducer와 UI 테스트 15개 통과
- ESLint 통과
- TypeScript 및 Vite 프로덕션 빌드 통과
