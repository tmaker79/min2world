# Milestone 17: 도로 건설

## 상태

보류

## 목표

건설자가 지도 위에 원래 지형을 보존하는 도로를 건설한다. 도로는 모든 세력의 이동 비용을 낮추지만 건설 세력은 보유한 도로 수에 따라 유지비를 부담한다. 도로는 거점·종속 확장과 별개인 타일 오버레이로 취급하고 전투·영토·수입 규칙은 바꾸지 않는다.

## 의존

- Milestone 12 유지비(도로 유지비와 다음 정산 예약액)
- Milestone 14 거점 건설(건설자 행동·후보 표시·확인 UI)
- Milestone 16 거점 확장(타일 오버레이 레이어와 공사 충돌 규칙)

## 핵심 개념

- **도로**: `Tile`의 원래 `terrain`을 바꾸지 않고 그 위에 놓이는 이동 오버레이다.
- **도로 소유 세력**: 도로를 완공한 건설자의 세력이다. 소유 세력은 유지비만 부담하며 도로 이용을 독점하지 않는다.
- **유효 이동 비용**: 도로가 있는 통행 가능 타일은 원래 지형과 관계없이 이동 비용 `2/3`을 사용한다. 이동력 2인 유닛은 도로만 따라 한 턴에 3칸 이동할 수 있다.
- **도로 유지비**: 한 세력이 소유한 도로 3칸마다 자원 1이다. 나머지가 있으면 한 묶음으로 올림한다.

```ts
type Tile = {
  // 기존 필드
  roadOwnerId?: FactionId
}

type GameAction =
  // 기존 액션
  | { type: 'roadBuilt'; unitId: string }
```

## 포함 범위

### 데이터와 소유권

- 도로는 `Terrain` 종류를 추가하지 않고 `Tile.roadOwnerId?: FactionId`로 저장한다. `terrain`, `terrainVariant`, `siteId`는 그대로 유지한다.
- `roadOwnerId`가 있으면 해당 타일에 완공된 도로가 한 칸 존재한다. 한 타일에는 도로를 하나만 둘 수 있다.
- 도로 ID, 레벨, 체력, 진행도와 별도 건설 횟수는 두지 않는다. 타일 위치가 도로를 식별한다.
- 도로 소유권은 건설 시점의 건설자 세력으로 고정한다. 타일이 적 영토·분쟁 지역·미편입 지역으로 바뀌거나 같은 타일의 거점이 점령되어도 자동 이전하지 않는다.
- 도로는 독립 거점이나 종속 확장이 아니다. 거점 수, 생산 거점 한도, 영토, 수입, 통제 구역과 승리 조건에 포함하지 않는다.
- 완공된 농지·방어진지·외곽 지구와 도로는 같은 타일에 공존할 수 있다. 도로는 부모 거점과 종속 확장의 소유권을 따르지 않는다.
- 도로가 먼저 놓인 타일에 이후 거점 본체나 종속 확장을 건설해도 도로는 유지한다. 거점·확장의 점령이나 제거도 도로 소유권과 존재 여부를 바꾸지 않는다.
- 진행 중인 `SiteConstructionProject`가 있는 타일의 기존 도로는 유지한다. 다만 공사에 묶인 건설자는 공사를 계속하거나 취소하기 전에는 도로 건설 행동을 할 수 없고, 다른 유닛은 같은 타일을 점유할 수 없으므로 공사 중 새 도로를 건설할 수 없다.
- 도로 상태를 구현할 때는 Milestone 16 완료 후 재개 시점의 다음 저장 스키마 번호를 사용한다. 바로 이전 스키마 저장은 모든 타일의 `roadOwnerId`가 없는 상태로 마이그레이션한다.
- 지도 생성 버전은 바꾸지 않는다. 새 게임 지도에는 완공된 도로를 자동 배치하지 않으며 도로는 플레이 중 액션으로만 생성한다.

### 도로 건설 규칙

- 활성 세력이 소유한 행동 가능한 건설자만 자신의 현재 타일에 도로를 건설할 수 있다.
- 대상 타일은 지도 안의 통행 가능한 육지여야 한다. 물·산·툰드라 산·다리에는 건설할 수 없다.
- 대상 타일에 이미 도로가 있으면 소유 세력과 관계없이 새 도로를 건설하거나 덮어쓸 수 없다.
- 거점 본체가 있는 타일에는 새 도로를 건설할 수 없다. 다만 도로 건설 후 같은 타일에 거점이 생기는 것은 허용하고 기존 도로를 유지한다.
- 완공된 농지·방어진지·외곽 지구가 있는 타일에는 도로를 건설할 수 있다. 도로는 종속 확장의 효과·한도·점령 규칙을 바꾸지 않는다.
- 대상 타일의 영토가 명확한 적 세력 소유이면 건설할 수 없다. 자기 영토·미편입 지역·분쟁 지역에는 건설할 수 있다.
- 도로 한 칸의 기본 건설 비용은 자원 2다. 실제 비용은 기존 세력별 비용 조정 규칙을 적용한다.
- `roadBuilt` 적용 전 비용과 건설 후 증가할 수 있는 도로 유지비 예약액을 함께 검사한다. 건설 후 도로 수가 `0 → 1`, `3 → 4`, `6 → 7`처럼 새 3칸 묶음을 시작할 때 `upkeepDelta: +1`을 예상 상태에 반영한다.
- 유효한 `roadBuilt`를 적용하면 비용 차감, `Tile.roadOwnerId` 설정, 건설자의 `movementRemaining: 0`, `hasActed: true`, 선택 해제를 하나의 상태 전이에서 처리한다.
- 도로 완공 후에도 건설자는 소모되지 않으며 같은 타일에 남는다. 다음 자기 턴부터 이동하거나 다른 도로·거점·확장을 건설할 수 있다.
- 잘못된 유닛 종류·활성 세력·소유권·행동 상태, 없는 타일, 금지 지형·영토, 기존 도로·거점·공사, 자원·유지비 예약액 부족으로 거부된 액션은 상태를 바꾸지 않는다.

### 이동과 다른 지도 규칙

- 도로가 없는 타일은 기존 `TERRAIN_MOVEMENT_COST`를 그대로 사용한다.
- 도로가 있는 통행 가능 타일로 들어가는 이동 비용은 모든 세력과 모든 유닛에 대해 `2/3`이다. 도로 소유 세력, 동맹 여부와 이동 방향은 확인하지 않는다.
- 현재 이동 규칙처럼 목적지 타일의 유효 이동 비용만 사용한다. 출발 타일에만 도로가 있는 경우 다음 칸의 비용을 낮추지 않는다.
- 평지·오아시스의 이동 비용은 도로가 있으면 1에서 `2/3`으로 낮아진다. 다리에는 도로를 건설할 수 없으므로 기존 비용 1을 유지한다.
- 언덕·숲·사막·사막 언덕·툰드라·툰드라 숲의 이동 비용은 도로가 있으면 2에서 `2/3`으로 낮아진다.
- 이동력 2인 보병·창병·궁병·개척자·건설자는 도로만 이동할 때 최대 3칸, 이동력 4인 기병은 최대 6칸 이동할 수 있다.
- 부동소수점 누적 오차를 피하도록 이동 비용 계산과 비교는 `1/3` 이동력 단위의 정수 tick으로 환산한다. 이동력 1은 3 tick, 도로 한 칸은 2 tick으로 계산하고 UI에는 기존 이동력 단위로 표시한다.
- 도로는 물·산 같은 불통 지형을 통행 가능하게 만들지 않으며 다리를 대체하지 않는다.
- 도로는 지형 전투 보너스, 방어진지 보너스, 통제 구역, 적 유닛·적 거점 차단과 점유 규칙을 무시하지 않는다.
- 지형 기반 정착·거점·확장 가능 여부, 광산의 언덕·산 인접 판정, 거점 사이 통행 가능 육지 그래프 거리는 원래 `terrain`을 사용한다. 도로 때문에 건설 가능한 지형이나 그래프 거리가 달라지지 않는다.
- 플레이어 이동 범위, 실제 이동 비용 검증, AI 가중 경로 탐색과 역방향 경로 비용은 하나의 유효 이동 비용 함수로 통일한다. `TERRAIN_MOVEMENT_COST`를 직접 읽어 도로를 무시하는 별도 경로 계산을 남기지 않는다.

### 경제와 턴 정산

- 세력별 기본 도로 유지비는 `ceil(소유 도로 수 / 3)`이다. 0칸은 0, 1~3칸은 1, 4~6칸은 2를 부담한다.
- 도로 유지비는 도로의 현재 영토나 이용 세력이 아니라 `roadOwnerId`로 집계한다. 적이 점유하거나 적 영토가 된 도로도 원래 소유 세력의 유지비에 포함한다.
- `getFactionUpkeep`은 유닛 유지비와 도로 유지비를 합산한다. 순수입, 다음 유지비 예약액, 상태바와 턴 종료 정산은 이 합계를 공통으로 사용한다.
- 턴 종료 정산은 기존과 같이 `max(0, 현재 자원 + 수입 - 전체 유지비)`를 적용한다. 도로 적자로 자원이 음수가 되거나 도로가 자동 제거되지는 않는다.
- 건설비와 도로 유지비 모두 임시 인간 세력 무료 경제 규칙을 포함한 기존 `getFactionAdjustedCost`를 따른다. 이 임시 규칙이 제거되면 별도 마이그레이션 없이 기본값이 적용된다.
- 도로 건설 후 유지비가 증가하지 않는 두 번째·세 번째 칸은 건설비만 예약액 판정에 반영한다. 새 묶음을 시작하는 첫 칸은 증가한 유지비까지 감당할 수 있어야 한다.

### 지도 표시와 조작

- 도로는 지형보다 위, Milestone 16의 종속 확장·공사와 거점·유닛보다 아래에 렌더링한다.
- 도로 이미지는 육각형 중심에서 도로가 있는 인접 타일 방향으로 이어지는 연결 형태를 사용한다. 인접 도로의 소유 세력이 달라도 시각적으로 연결한다.
- 도로가 종속 확장과 같은 타일에 있으면 밭·방어진지·외곽 지구 아래로 지나가되 연결 방향을 알아볼 수 있어야 한다.
- 도로 소유 세력은 작은 색상 표식이나 툴팁으로 구분하고, 모든 세력이 이용할 수 있다는 점과 현재 이동 비용 `2/3`을 함께 표시한다. 소유 깃발을 도로마다 반복하지 않는다.
- 미니맵에는 지형색과 영토색을 대체하지 않는 가는 도로 표식을 사용한다. 축소 상태에서 식별이 어려우면 개별 소유 색보다 연결망 형태를 우선한다.
- 건설자를 선택하면 기존 거점·확장 건설 메뉴와 함께 `도로 건설`을 표시한다. 선택 시 현재 타일의 가능 여부, 비용 2, 건설 후 전체 도로 유지비와 다음 묶음 증가 여부를 보여 준다.
- 도로 건설을 선택하면 현재 타일을 후보로 강조하고 확인 후 `roadBuilt`를 보낸다. `Esc`는 도로 건설 선택·확인 단계만 취소하며 이미 완공된 도로에는 영향을 주지 않는다.
- 건설 불가 상태는 잘못된 지형, 적 영토, 기존 도로, 거점 본체, 진행 중 공사, 자원 부족, 유지비 예약액 부족과 이미 행동한 건설자를 구분해 안내한다.
- 도로가 있는 타일의 정보창과 접근성 라벨에는 원래 지형, 원래 이동 비용, 도로 적용 이동 비용 `2/3`, 도로 소유 세력을 표시한다.

### AI

- AI의 모든 유닛 경로 탐색은 플레이어와 같은 유효 이동 비용을 사용해 인간이나 다른 AI가 건설한 도로도 이용한다.
- 진행 중인 공사를 가진 건설자는 기존처럼 공사 계속을 가장 먼저 평가한다. 즉시 가능한 거점·종속 확장 건설 후보가 있으면 도로보다 우선한다.
- AI는 도로 건설만을 이유로 새 건설자를 생산하지 않는다. 다른 목적으로 생산되어 현재 즉시 수행할 상위 건설 후보가 없는 건설자만 도로 후보를 평가한다.
- 도로 후보는 아군 Town·City와 다른 아군 Town·City·생산 거점·군사 거점 사이의 통행 가능한 최단 경로에 포함된 도로 없는 타일로 만든다. 적 영토·금지 지형·거점 본체·진행 중 공사 타일은 제외한다.
- AI는 원래 이동 비용이 `2/3`보다 큰 모든 합법 타일을 도로 후보로 사용한다. 비용 절감량이 큰 거친 지형을 평지·오아시스보다 먼저 포장한다.
- 같은 상태의 후보는 해당 칸의 이동 비용 절감량 내림차순, 연결 대상 경로의 총비용 내림차순, 건설자에서 후보까지의 경로 비용 오름차순, 대상 거점 ID, `r`, `q` 오름차순으로 고른다.
- 건설자가 후보 타일에 있으면 플레이어와 같은 비용·증가 유지비 예약액 판정을 거쳐 도로를 건설한다. 후보에 없으면 기존 민간 유닛 경로 규칙으로 이동하고 다음 턴에 다시 평가한다.
- 도로 비용이나 새 유지비 묶음을 감당할 수 없으면 자원을 음수로 만들지 않고 대기한다. 도로를 위해 군사 유닛을 해산하거나 다른 투자 규칙의 우선순위를 바꾸지 않는다.

## 구현 순서

1. `Tile.roadOwnerId`, `roadBuilt` 액션, 도로 건설 비용·가능 판정과 재개 시점의 다음 스키마 마이그레이션·저장 검증을 추가한다.
2. 유효 이동 비용 함수를 만들고 플레이어 이동 범위·reducer 검증·AI 경로 탐색이 공통으로 사용하도록 정리한다.
3. 도로 수 집계와 3칸 단위 유지비를 전체 유지비·순수입·예약액·턴 종료 정산에 연결한다.
4. 건설자 도로 선택·확인·실패 안내와 원자적 완공 상태 전이를 구현한다.
5. 지형 위 도로 연결 오버레이, 종속 확장과의 레이어 순서, 미니맵·정보창·툴팁·접근성 표시를 추가한다.
6. AI가 기존 도로를 경로에 반영하고 남는 건설자로 거점 사이 거친 지형을 결정론적으로 포장하도록 연결한다.
7. 규칙·reducer·경제·AI·저장·UI 회귀 테스트를 추가하고 린트와 프로덕션 빌드를 실행한다.

## 제외 범위

- 도로 철거·소유권 양도·점령·파괴·약탈·복구
- 적 도로 이용 제한, 통행료와 외교·동맹에 따른 이용 권한
- 건설자 여러 명의 공동 작업, 도로 건설 진행도와 건설 시간 증가
- 물 위 다리 건설, 터널과 불통 지형 개통
- 철도·고속도로 같은 도로 레벨과 기술 연구
- 무역로, 거점 사이 연결 수입과 자원 운송
- 도로를 이용한 보급망·사기·시야 확장
- 연속 도로 길이·완전 연결에 따른 추가 이동 보너스
- 도로 자동 제거와 적자 시 강제 폐쇄

## 검증 계획

- 도로가 원래 지형·변형·거점 참조를 보존하고 한 타일에 중복 생성되지 않는지 규칙·reducer 테스트로 검증한다.
- 자기 영토·미편입·분쟁 지역은 허용하고 적 영토, 물·산·툰드라 산·다리·거점 본체·진행 중 공사는 거부하는지 검증한다.
- 비용 2 차감, 건설자 존속·행동 종료·선택 해제와 무효 액션의 상태 불변성을 검증한다.
- 모든 세력이 도로를 이용하며 평지·오아시스는 1에서 `2/3`, 거친 지형은 2에서 `2/3`으로 낮아지고 불통 지형·다리·전투 보정·통제 구역·건설 지형 판정은 바뀌지 않는지 검증한다.
- 이동력 2 유닛이 도로 3칸, 이동력 4 유닛이 도로 6칸을 정확히 이동하고 `1/3` tick 환산으로 누적 오차나 경계 초과 이동이 생기지 않는지 검증한다.
- 플레이어 도달 범위, 실제 이동 비용, AI 정방향·역방향 경로 탐색이 같은 도로 비용을 사용하는지 검증한다.
- 도로 0·1·3·4·6·7칸의 유지비가 각각 0·1·1·2·2·3이고 유닛 유지비와 정확히 합산되는지 검증한다.
- 새 3칸 묶음을 시작할 때만 `upkeepDelta: +1`을 적용하고 비용·예약액 부족 시 건설을 거부하는지 검증한다.
- 영토 변화·거점 점령·종속 확장 점령 뒤에도 도로 소유권과 유지비 부담자가 유지되는지 검증한다.
- 도로와 완공된 농지·방어진지·외곽 지구가 같은 타일에 공존하고 레이어·클릭·효과 우선순위가 유지되는지 검증한다.
- 구현 직전 스키마 저장이 도로 없음으로 마이그레이션되고 새 스키마 왕복 후 위치·소유권이 유지되며 잘못된 세력·불통 지형 도로 저장은 거부되는지 검증한다.
- AI가 기존 도로를 이용하고 상위 건설 행동을 우선하며, 새 건설자를 도로만을 위해 생산하지 않고 같은 상태에서 같은 거친 지형 후보를 고르는지 검증한다.
- 도로 연결 표시, 후보 강조, 확인·`Esc` 취소, 유지비 증가 안내, 정보창·툴팁·접근성 라벨과 미니맵 표식을 UI 테스트로 검증한다.
- 기존 지도 생성 결과에는 도로가 없고 같은 seed의 지형·거점 배치가 바뀌지 않는지 검증한다.
- 전체 테스트, 린트와 프로덕션 빌드를 실행한다.

## 완료 조건

- 플레이어와 AI가 건설자로 합법적인 현재 타일에 도로를 건설할 수 있다.
- 도로 건설은 비용 2를 차감하고 건설자를 남긴 채 해당 턴 행동을 종료한다.
- 도로는 원래 지형과 거점·종속 확장 정보를 보존하며 모든 세력의 해당 타일 이동 비용을 `2/3`으로 만든다.
- 도로가 불통 지형, 전투 보정, 통제 구역, 영토와 지형 기반 건설 규칙을 바꾸지 않는다.
- 세력별 도로 유지비가 3칸마다 1씩 올림되어 유닛 유지비·순수입·예약액·턴 정산에 일관되게 반영된다.
- 도로 소유권은 영토 변화·거점 점령과 무관하게 유지되고 모든 세력이 같은 이동 이점을 받는다.
- 지도·미니맵·정보창에서 도로 연결, 소유 세력, 적용 이동 비용과 유지비를 확인할 수 있다.
- AI가 기존 도로를 경로 계산에 사용하고 남는 건설자로 거점 사이 거친 지형을 결정론적으로 포장한다.
- 저장·불러오기 후 도로 위치와 소유권이 유지되고 기존 저장은 도로 없는 상태로 정상 마이그레이션된다.
- 관련 테스트, 린트와 프로덕션 빌드가 통과한다.

## 후속 목표

도로 철거·점령·약탈과 복구, 다리 건설, 무역로·통행료, 도로 기반 보급망과 상위 도로를 별도 마일스톤으로 검토한다.
