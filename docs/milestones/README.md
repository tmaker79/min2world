### 가까운 후보

- 여러 저장 슬롯, 자동 저장, 파일 내보내기/가져오기
- 전장의 안개
- 전투 사운드, 이동 경로 연출

### 큰 확장

- 맵·세력 규모 확장: 현재 2인용 맵·2세력에서 향후 2~8세력을 자유롭게 선택
- 장수 능력과 장비
- 유닛 경험치와 승급
- 범위 공격, 치명타 등 확률 전투
- 도시 방어력과 공성전
- 기술 연구, 세력 외교
- 서버·클라우드 저장과 게임 기록 공유
- PixiJS 렌더러, Zustand UI 상태 관리
