# Milestone 16: 거점 확장

## 상태

다음 목표

## 목표

농장을 한 타일짜리 아이콘이 아니라 본체와 주변 생산지로 이루어진 거점으로 확장한다. 농장 본체는 헛간과 소규모 작물이 있는 기존 이미지를 사용하고, 인접 타일에 확장한 농지는 넓은 밭 이미지를 한 칸마다 하나씩 표시한다.

군사 거점은 영토 밖 요충지에도 세울 수 있는 만큼 Outpost의 즉시 완공을 총 3회의 건설 행동으로 바꾸고, Outpost·Keep·Stronghold 주변에는 방향성 있는 방어진지를 확장할 수 있게 한다. 방어진지는 주둔 아군의 방어와 군사 거점의 통제 구역을 강화하지만 수입·생산·영토는 만들지 않는다.

이 단계의 종속 확장은 Farm의 농지와 군사 거점의 방어진지만 대상으로 삼는다. Mine·Blacksmith와 정착 계열의 전용 확장, 방어진지의 세부 병과 분화는 후속으로 미룬다. Village·Town·City는 모두 기준 위치 한 칸을 사용하며 종속 확장과 구분한다.

## 의존

- Milestone 10 거점 개발(`Site.level`, `lastDevelopedTurn` 재사용)
- Milestone 11 성 내정(건설 UI 패턴 재사용)
- Milestone 14 거점 건설(새 농장의 확장 규칙과 Outpost 건설 공정 변경)

## 핵심 개념

- **농장 본체**: `SiteType: 'farm'`인 기존 `Site`. 점령·수입·선택의 기준점이다.
- **농지**: 농장 본체에 종속된 인접 타일 확장. 독립 거점이 아니며 별도 소유자를 갖지 않는다.
- **확장 한도**: 농장 본체의 `level`과 같다. 농장 레벨이 오를 때마다 농지를 한 칸 더 확장할 수 있다.
- **군사 거점 공사**: Outpost를 즉시 생성하지 않고 동일 건설자가 세 번의 행동으로 완공하는 타일 공사다.
- **방어진지**: 군사 거점에 종속된 인접 타일 확장. 독립 거점이 아니며 아군 군사 유닛의 방어와 부모 거점의 통제 구역을 한 방향으로 확장한다.
- 농장 본체 타일에는 헛간 중심 이미지를 표시한다.
- 농지 타일에는 넓은 황금색 밭 이미지를 표시한다.
- 방어진지 타일에는 목책·말뚝·토루를 조합한 방어 시설 이미지를 표시한다.
- 농지와 방어진지는 육각 타일 한 칸을 차지하지만 원래 지형과 유닛 이동을 대체하지 않는다.

```text
      [농지]
 [농지][농장][빈칸]
      [농지]
```

## 포함 범위

### 데이터

```ts
type SiteExpansion = {
  siteId: string
  kind: 'farm-field' | 'defensive-position'
  position: Position
}

type SiteConstructionProject =
  | {
      unitId: string
      factionId: FactionId
      kind: 'outpost'
      position: Position
      progress: 1 | 2
    }
  | {
      unitId: string
      factionId: FactionId
      kind: 'defensive-position'
      siteId: string
      position: Position
      progress: 1
    }

type GameState = {
  // 기존 필드
  siteExpansions: SiteExpansion[]
  siteConstructionProjects: SiteConstructionProject[]
}
```

- 종속 확장의 소유권은 `siteId`가 가리키는 부모 거점에서 파생한다. 소유권을 중복 저장하지 않는다.
- 한 타일에는 종류와 관계없이 종속 확장을 하나만 둘 수 있다.
- 확장 타일은 `Tile.siteId`를 사용하지 않는다. 농지와 방어진지는 독립 거점이 아니며 유닛 이동을 막지 않기 때문이다.
- 공사 프로젝트는 완공 전까지 `Site`나 `SiteExpansion`으로 취급하지 않는다.
- 스키마를 15로 올리고 스키마 14 저장은 `siteExpansions: []`, `siteConstructionProjects: []`로 마이그레이션한다.
- Milestone 15가 보류된 동안 Milestone 16을 먼저 구현하므로 이 변경이 스키마 15를 사용한다. Milestone 15를 재개할 때는 그 시점의 다음 스키마 번호를 사용한다.
- `siteId`, 확장 종류와 위치 키를 합친 값을 종속 확장의 결정론적 식별자로 사용하며 별도 ID나 소유권은 저장하지 않는다.
- 저장 검증 시 종류별 부모 거점, 지형·인접 관계, 전역 위치 중복, 지도 범위, 부모 단계별 한도와 동일 타일의 거점·다른 공사 부재를 확인한다. 완공된 확장 타일의 유닛 점유는 불러오기를 막지 않는다.
- 공사 프로젝트는 종류·진행도, 동일 위치의 건설자와 세력, 지도·지형 범위, 부모 군사 거점과 확장 한도, 거점·확장·다른 공사 중복을 검증한다.

### 농장 레벨과 확장 한도

Milestone 10에서 도입한 농장 1~3레벨과 `lastDevelopedTurn`을 재사용한다. 기존 레벨별 비용과 기본 수입은 유지하되, 농장에 한해 현재 레벨의 농지를 모두 확장해야 다음 레벨로 발전할 수 있다.

| 농장 레벨 | 농지 확장 한도 |
| ---: | ---: |
| 1 | 1칸 |
| 2 | 2칸 |
| 3 | 3칸 |

- 새 게임의 기존 농장과 Milestone 14에서 새로 건설한 농장은 1레벨·농지 0칸으로 시작한다.
- 농장 레벨업 비용과 기본 수입 증가는 Milestone 10의 거점 개발 표를 따른다.
- 농장 발전과 농지 확장은 같은 농장의 턴당 경제 행동을 공유한다. `lastDevelopedTurn === turn`이면 둘 다 실행할 수 없으며, 어느 한쪽을 실행하면 `lastDevelopedTurn`을 현재 턴으로 설정한다.
- 새로 건설한 농장은 기존 건설 규칙에 따라 `lastDevelopedTurn`이 현재 턴이므로 다음 턴부터 농지를 확장할 수 있다.
- 점령 시 농장 레벨과 농지는 모두 유지된다.

### 정착 거점별 생산 슬롯

- 생산 특화 시설을 한 정착지 주변에 무제한으로 집중하지 못하도록 정착 거점마다 생산 슬롯을 둔다.

| 지원 정착 거점 | 생산 거점 한도 |
| --- | ---: |
| Village | 0개 |
| Town | 2개 |
| City | 4개 |

- Farm·Mine·Blacksmith 본체는 각각 생산 슬롯 1개를 사용한다. 농지 확장은 독립 거점이 아니므로 슬롯을 사용하지 않는다.
- Outpost·Keep·Stronghold는 생산 슬롯의 지원 거점이나 사용 대상으로 취급하지 않는다.
- 생산 거점의 지원 정착지는 현재 소유 세력의 Town·City 중 통행 가능한 육지 그래프 거리 3 이내인 후보로 정한다. 가장 가까운 후보를 우선하고 거리가 같으면 정착 거점 ID 오름차순으로 결정한다.
- 지원 관계와 사용 슬롯 수는 현재 거점 상태에서 계산하는 파생 정보로 두며 저장하지 않는다. Town이 City로 발전하거나 정착지·생산 거점이 점령되면 즉시 다시 계산한다.
- 새 Farm·Mine·Blacksmith는 지원 정착지가 있고 해당 정착지의 사용 슬롯이 한도보다 적을 때만 건설할 수 있다. 이 규칙은 기존 자기 영토·지형·거점 간격 조건과 함께 적용한다.
- 점령·발전·지원 관계 변경으로 한도를 초과해도 기존 생산 거점을 제거하거나 수입·발전·농지 확장을 정지하지 않는다. 해당 정착지의 사용량이 한도 아래로 내려갈 때까지 새 생산 거점 건설만 막는다.
- 중립 생산 거점은 어느 정착지의 슬롯도 사용하지 않는다. 점령되면 새 소유 세력의 지원 정착지를 다시 계산해 슬롯에 포함한다.
- `productionCapacityReached` 실패 사유를 추가하고 “이 정착지의 생산 거점 한도에 도달했습니다.”로 안내한다. UI 후보 표시, reducer와 AI가 같은 지원 정착지·슬롯 판정을 사용한다.

### Outpost 3회 건설

- Farm·Mine·Blacksmith의 건설은 기존처럼 비용을 지불한 턴에 즉시 완공한다. 직접 건설하는 군사 거점인 Outpost만 타일 공사로 전환한다.
- 첫 번째 건설 행동에서 기존 Outpost 배치 판정을 모두 통과해야 한다. 자원 10을 전액 지불하고 `progress: 1`인 공사를 만든 뒤 건설자의 `movementRemaining: 0`, `hasActed: true`로 해당 턴 행동을 끝낸다.
- 같은 건설자가 같은 타일에서 다음 자기 턴마다 `건설 계속` 행동을 사용해 진행도를 올린다. 두 번째 행동은 `2/3`, 세 번째 행동은 Outpost 완공이며 각 행동 뒤 건설자의 이동력과 행동을 종료한다.
- 공사 중인 타일에는 거점·종속 확장·다른 공사·정착을 시작할 수 없다. 공사는 수입·방어력·통제 구역·영토·생산 능력과 거점 거리 판정을 만들지 않는다.
- 건설자가 죽거나 제거되거나 공사 타일을 떠나면 공사를 즉시 취소한다. 플레이어가 명시적으로 취소할 수도 있으며 이미 지불한 비용은 환불하지 않는다.
- 시작 이후 영토가 적 영토로 바뀌어도 동일 건설자가 남아 있으면 공사를 계속할 수 있다. 적 영토 금지는 첫 번째 건설 행동에서만 검사한다.
- 세 번째 행동은 공사 제거, Outpost 생성, `Tile.siteId` 설정과 건설자 행동 종료를 하나의 상태 전이에서 처리한다. 신규 Outpost의 기본값은 Milestone 14 규칙을 유지한다.
- Outpost → Keep → Stronghold 발전은 기존처럼 즉시 처리한다. 이번 단계에서는 상위 군사 거점 발전에 별도 공사 시간을 추가하지 않는다.
- `{ type: 'siteConstructionStarted'; unitId: string; constructionKind: 'outpost' }`와 `{ type: 'siteConstructionAdvanced'; unitId: string }` 액션을 추가하고 UI·reducer·AI가 같은 시작·계속 판정을 사용한다.

### 군사 거점 방어진지

| 부모 군사 거점 | 방어진지 한도 |
| --- | ---: |
| Outpost | 1칸 |
| Keep | 2칸 |
| Stronghold | 3칸 |

- 현재 세력이 소유한 부모 군사 거점과 육각 거리 1인 일반 평지·언덕·숲에 건설자 하나가 서 있을 때 방어진지 공사를 시작할 수 있다.
- 적 영토에는 새 공사를 시작할 수 없으며 자기 영토·미편입·분쟁 지역은 허용한다. 시작 후 영토가 바뀌어도 공사는 유지한다.
- 대상 타일에는 행동하는 건설자 외의 유닛, 거점, 다른 종속 확장이나 공사가 없어야 한다. 완공 후에는 유닛이 이동하거나 머물 수 있다.
- 방어진지 하나의 비용은 자원 6이며 총 2회의 건설 행동이 필요하다. 첫 행동에서 비용을 전액 지불하고 `progress: 1` 공사를 만들며, 다음 자기 턴의 `건설 계속` 행동으로 완공한다.
- 진행 중인 방어진지 공사도 부모 단계별 한도에 포함한다. 여러 건설자가 동시에 공사를 시작해 완공 한도를 초과할 수 없다.
- 건설자가 죽거나 타일을 떠나거나 공사를 취소하면 환불 없이 공사가 제거된다. 공사 중 부모 거점이 다른 세력에 점령되거나 제거되어도 공사를 취소한다.
- 완공된 방어진지 위의 부모 거점 소유 세력 군사 유닛은 기존 지형 방어 보정에 15%p를 가산한다. 민간 유닛과 적 유닛은 보너스를 받지 않는다.
- 방어진지는 자신과 인접한 타일에 부모 군사 거점과 같은 통제 구역을 만든다. 적 유닛이 방어진지 타일을 점유한 동안에는 방어 보정과 통제 구역 확장을 모두 비활성화한다.
- 방어진지 자체는 점령 대상이 아니다. 부모 거점이 점령되면 완공된 방어진지도 함께 귀속되고, 부모 거점이 제거되면 함께 제거된다.
- 방어진지는 수입·생산·영토를 만들지 않고 독립 거점 수나 거점 거리 제한에 포함되지 않는다. 같은 타일의 이후 정착·거점 건설과 다른 종속 확장만 막는다.
- 방어진지 공사는 `siteConstructionStarted`의 `constructionKind: 'defensive-position'`과 `siteId`로 시작하고, 완공 시 `kind: 'defensive-position'`인 `SiteExpansion`을 원자적으로 추가한다.

### 농지 확장 규칙

- 활성 세력이 소유한 농장에서만 확장할 수 있다.
- 농장 본체와 육각 거리 1인 인접 평지에만 농지를 추가할 수 있다.
- 대상 타일의 영토 소유자가 농장 소유 세력과 같아야 한다. 미편입·적·분쟁 지역에는 새 농지를 확장할 수 없다.
- 대상 타일에 거점, 다른 종속 확장이나 진행 중인 공사가 있으면 확장할 수 없다.
- 건설 시점에 유닛이 있는 타일에는 확장할 수 없다. 완공 후에는 유닛이 농지 위로 이동하거나 머물 수 있다.
- 완공된 농지는 같은 타일의 이후 정착과 모든 거점 건설을 막는다. 다만 독립 거점이 아니므로 정착·생산·군사 거점의 거리 제한 계산에는 포함하지 않는다.
- 농장 하나의 농지 수는 현재 농장 레벨을 넘을 수 없다. 1레벨은 1칸, 2레벨은 2칸, 3레벨은 3칸까지 확장한다.
- 농지 한 칸의 확장 비용은 자원 10이다.
- 대기열 없이 즉시 완공하지만 같은 농장은 한 턴에 한 번만 발전하거나 확장할 수 있다.
- UI 후보 표시, reducer 액션과 AI가 같은 순수 확장 판정을 사용한다. 실제 액션은 `{ type: 'siteExpanded'; siteId: string; position: Position }`으로 처리하고 모든 조건을 다시 검증한 뒤 비용 차감과 농지 추가를 원자적으로 수행한다.

### 경제

- 농장 본체 수입은 Milestone 10의 레벨별 기본 수입(2/3/4)을 사용한다.
- 농지 한 칸마다 해당 농장 수입이 +1 증가한다.
- 3레벨에서 농지 3칸을 모두 확장한 농장의 총수입은 7이다.
- 턴 수입 계산은 농장 본체 소유자에게 본체와 종속 농지 수입을 합산한다.
- `getSiteIncome(site)`은 본체 기본 수입 계산으로 유지하고, `getFactionIncome(state, factionId)`에서 소유 농장의 농지 수입을 더한다. 상태바·정보창·AI·예약 유지비가 같은 합산 결과를 사용한다.
- 확장 비용 판정은 기존 `canSpendWithUpkeepReserve`에 `incomeDelta: +1`을 전달한다. 플레이어와 AI 모두 같은 자원·예약 유지비 규칙을 적용하며 별도의 고정 잔여 자원 기준을 두지 않는다.

### 종속 확장의 점령과 제거

- 적이 농장 본체를 점령하면 종속 농지는 별도 행동 없이 새 소유자에게 귀속된다.
- 점령이나 영토 변화로 기존 농지가 새 소유자의 영토 밖에 놓여도 제거하지 않는다. 자기 영토 조건은 새 확장 시점에만 검사한다.
- 농지 타일 위의 유닛은 농장 소유권을 바꾸지 않는다. 점령 판정은 본체 타일에서만 발생한다.
- 적이 군사 거점 본체를 점령하면 완공된 방어진지도 새 소유자에게 귀속된다. 방어진지 타일 위의 유닛은 소유권을 바꾸지 않으며 적 점유 중에는 방어진지 효과만 비활성화한다.
- 농장 본체가 제거되는 후속 기능이 생기면 종속 농지도 함께 제거한다.
- 농지와 방어진지는 개별 약탈·파괴 대상이 아니다. 파괴와 복구는 후속 범위로 둔다.

### 지도 표시와 조작

- 농장 본체는 헛간·작물이 함께 있는 기존 농장 이미지를 사용한다.
- 농지는 현재의 넓고 낮은 황금색 밭 이미지를 타일마다 표시한다.
- 농지 레이어는 지형보다 위, 거점·유닛보다 아래에 렌더링한다.
- 농지 이미지는 육각 경계를 넘지 않으며 지형 그림을 완전히 가리지 않도록 크기를 제한한다.
- 농지 타일을 클릭하면 부모 농장 정보창을 연다.
- 농지 위에 유닛이 있으면 유닛 선택을 우선하고, 유닛이 없을 때 부모 농장 정보창을 연다.
- 농지 툴팁에 `농지`, 부모 농장 이름, `수입 +1`을 표시한다.
- 농지 타일에 식별용 데이터 속성과 부모 농장을 포함한 접근성 라벨을 제공한다.
- 방어진지는 지형보다 위, 거점·유닛보다 아래인 종속 확장 레이어에 목책·토루 이미지로 표시한다. 활성 상태와 적 점유로 비활성화된 상태를 색과 아이콘으로 구분한다.
- 방어진지 타일을 클릭하면 유닛 선택을 우선하고 유닛이 없으면 부모 군사 거점 정보창을 연다. 툴팁과 접근성 라벨에 부모 거점, `아군 방어 +15%`, 통제 구역 확장과 현재 활성 상태를 표시한다.
- 진행 중인 Outpost·방어진지 공사는 기초 공사 이미지와 `1/3`, `2/3`, `1/2` 진행도를 지도에 표시하며 거점이나 완공된 확장과 시각적으로 구분한다.
- 소유 세력 깃발은 부모 거점 본체에만 표시하고 종속 확장마다 반복하지 않는다.

### UI

- 소유 Farm·Mine·Blacksmith 정보창과 건설 확인 UI에 지원 Town·City와 해당 정착지의 생산 슬롯 사용량을 표시한다.
- 소유 농장 정보창에 현재 레벨, 농지 수/레벨별 한도, 다음 레벨 비용, 다음 확장 비용과 총수입을 추가로 표시한다.
- 현재 농지 수가 레벨 한도에 도달하면 `농장 개발` 버튼으로 다음 레벨을 먼저 올리도록 안내한다.
- `농지 확장`을 선택하면 건설 가능한 인접 평지를 강조한다.
- 강조된 타일을 선택하면 비용과 수입 증가를 확인한 뒤 확장한다.
- 자원 부족, 예약 유지비 부족, 현재 턴 행동 완료, 자기 영토 밖, 타일 점유, 현재 레벨 한도 도달, 3레벨·3칸 최대 도달, 유효한 인접 평지 없음 상태를 구분해 안내한다.
- Outpost 건설 확인 UI에 비용 10, 총 3회의 건설 행동, 건설자 구속과 취소 시 환불 없음까지 표시한다. 공사 중 건설자 정보창에는 진행도와 `건설 계속`, `공사 취소`를 노출한다.
- 소유 군사 거점 정보창에 현재 방어진지 수/단계별 한도와 효과를 표시한다. 건설자가 합법적인 인접 타일에 있으면 비용 6과 총 2회의 행동을 확인한 뒤 방어진지 공사를 시작할 수 있다.
- `Esc`는 건설 후보나 확인 단계만 취소하며 이미 시작된 공사는 취소하지 않는다. 진행 중 공사는 별도 `공사 취소` 확인을 거쳐야 한다.

### AI

- 진행 중인 공사가 있는 AI 건설자는 다른 이동·건설 후보보다 `건설 계속`을 우선한다. 건설자가 제거되거나 부모 군사 거점을 잃어 공사가 취소된 경우에만 일반 행동 평가로 돌아간다.
- AI의 Outpost 건설 후보는 기존 전선·요충지 우선순위를 유지하되 즉시 거점을 만들지 않고 3회 공사를 시작한다. 비용은 첫 행동에서만 지불하고 다음 행동에서는 중복 차감하지 않는다.
- AI는 부모 단계의 한도가 남은 군사 거점에서 방어진지 후보를 평가한다. 새로 통제하게 되는 적 접근 가능 인접 칸 수가 많은 위치, 언덕 → 숲 → 평지, 부모 거점 ID, `r`, `q` 순으로 결정한다.
- Outpost와 방어진지 공사 시작은 플레이어와 동일한 배치·자원·예약 유지비 판정을 사용한다.
- 농장 개발과 농지 확장을 기존 `chooseInvestment`의 통합 투자 후보에 포함한다. AI는 모든 군사 행동을 마친 뒤 City 건설·거점 발전·농지 확장 중 세력 턴당 하나만 선택한다.
- 농지가 현재 레벨 한도에 도달한 농장만 다음 레벨 개발 후보가 된다. 확장 후보는 현재 레벨 한도 미만이고 합법적인 자기 영토 인접 평지가 있는 농장이다.
- 개발과 확장 모두 플레이어와 동일한 `canSpendWithUpkeepReserve` 판정을 사용한다. 농지 확장은 비용 10, 수입 증가 1, 회수 기간 10턴인 수입 투자로 평가한다.
- 같은 투자 등급과 회수 기간에서는 후보 농장을 현재 농지 수 오름차순, 농장 ID 오름차순으로 선택한다.
- 후보 타일은 `r`, `q` 오름차순으로 선택해 결정론을 유지한다.
- AI는 Farm·Mine·Blacksmith 건설 후보를 평가할 때 지원 정착지의 생산 슬롯을 확인한다. 한도를 초과한 기존 농장의 발전·농지 확장은 계속 평가하지만 해당 정착지에 새 생산 거점은 건설하지 않는다.

## 구현 순서

1. 농장 본체·농지·방어진지·공사 진행도 에셋을 준비하고 공통 종속 확장 레이어를 구성한다.
2. `SiteExpansion`, `SiteConstructionProject` 데이터와 스키마 15 마이그레이션·검증을 추가한다.
3. 공통 공사 시작·계속·취소 판정과 reducer 액션을 구현하고 Outpost의 3회 건설을 연결한다.
4. 지원 Town·City 귀속과 정착 단계별 생산 슬롯 인덱스를 추가하고 생산 거점 건설 판정에 연결한다.
5. 기존 농장 레벨과 레벨별 확장 한도, 발전 선행 조건과 턴당 경제 행동 제한을 연결한다.
6. 농지 확장 가능 위치, 기존 정착·거점 건설과의 동일 타일 충돌, 수입·예약 유지비 계산 규칙과 reducer 액션을 구현한다.
7. 군사 거점 단계별 방어진지 한도, 2회 공사, 방어 보정·통제 구역·점령 규칙을 연결한다.
8. 지도 종속 확장·공사 레이어와 생산·군사 거점 정보창의 조작을 연결한다.
9. AI 공사 계속·방어진지 정책과 저장·점령·UI 테스트를 추가한다.

## 제외 범위

- Mine·Blacksmith와 정착 거점의 종속 확장
- 성벽·망루·보급창·포대처럼 역할이 다른 군사 확장과 방어진지의 개별 업그레이드
- 방어진지의 이동 차단·이동 비용 변경·직접 공격·시야·보급 효과
- Keep·Stronghold 발전의 건설 시간과 여러 건설자가 한 공사를 함께 진행하는 기능
- 농지 개별 점령·파괴·약탈·복구
- 작물 종류, 계절, 식량 자원 분리
- 농지 전용 이동 비용이나 전투 보정
- 농장 본체에서 두 칸 이상 떨어지는 연결형 확장

## 검증 계획

- 레벨별 한도, 현재 레벨 농지를 모두 채운 뒤 발전하는 순서, 농장별 턴당 발전·확장 1회와 새 농장의 같은 턴 확장 금지를 규칙 테스트로 검증한다.
- 평지·인접·자기 영토 조건, 지도 가장자리, 거점·농지·유닛 점유와 미편입·적·분쟁 영토 실패 사유를 검증한다.
- Village 0개·Town 2개·City 4개의 생산 슬롯, 가장 가까운 지원 정착지와 ID 동률 판정, 농지·군사 거점의 슬롯 제외를 검증한다.
- 점령·발전으로 지원 관계와 슬롯이 즉시 재계산되고 초과한 기존 생산 거점은 유지되지만 새 건설만 차단되는지 검증한다.
- 농지가 있는 동일 타일의 이후 정착·거점 건설은 거부되고 다른 거점의 거리 계산과 유닛 이동·전투에는 포함되지 않는지 검증한다.
- Outpost가 첫 행동에서만 비용 10을 지불하고 `1/3 → 2/3 → 완공`되며 매 행동마다 건설자가 종료되는지 검증한다.
- Outpost 공사 중에는 모든 거점 효과와 거리 판정이 없고, 건설자 사망·이탈·명시적 취소 시 환불 없이 제거되며 영토 변화만으로는 취소되지 않는지 검증한다.
- Outpost·Keep·Stronghold의 방어진지 한도 1/2/3, 일반 평지·언덕·숲과 적 영토 제외, 진행 중 공사를 포함한 한도 판정을 검증한다.
- 방어진지가 첫 행동에서만 비용 6을 지불하고 두 번째 행동에 완공되며 부모 점령·제거, 건설자 사망·이탈 시 규칙대로 귀속 또는 취소되는지 검증한다.
- 방어진지 위 아군 군사 유닛의 지형 방어 보정 +15%p, 통제 구역 확장, 적 점유 중 비활성화와 민간·적 유닛 보너스 제외를 검증한다.
- 비용 차감, 예약 유지비와 `incomeDelta: +1`, 원자적 농지 추가, 무효 액션의 상태 불변성을 reducer 테스트로 검증한다.
- 레벨별 본체 수입과 농지 수입 합산, 점령 후 귀속, 영토 변화 후 기존 농지 유지와 상태바·정보창 표시를 검증한다.
- 스키마 14 마이그레이션과 스키마 15 왕복, 잘못된 부모·종류·지형·인접·중복·한도·동일 타일 거점 저장의 거부를 검증한다.
- 지도 레이어 순서, 공사 진행도, 후보 강조, 확인·취소와 `Esc`, 유닛과 종속 확장의 클릭 우선순위, 툴팁·접근성 속성을 UI 테스트로 검증한다.
- AI가 진행 중 공사를 우선하고 Outpost·방어진지 비용을 중복 차감하지 않으며 방어진지와 농지 후보의 결정론적 동률 규칙을 지키는지 검증한다.
- AI가 농지 확장을 통합 투자 1회 제한 안에서 평가하고 예약 유지비, 회수 기간과 농장·좌표 동률 규칙을 지키는지 검증한다.
- 전체 테스트, 린트와 프로덕션 빌드를 실행한다.

## 완료 조건

- 농장 본체와 농지가 서로 다른 이미지로 명확히 구분된다.
- 플레이어와 AI가 농장 레벨을 올리고, 현재 레벨만큼 인접 평지에 농지를 확장할 수 있다.
- 농지는 자기 영토에만 확장되고 농지 위의 이후 정착·거점 건설은 거부되지만 다른 거점의 거리 제한에는 영향을 주지 않는다.
- Farm·Mine·Blacksmith는 지원 Town·City의 생산 슬롯 안에서만 새로 건설되며 농지 확장은 슬롯을 사용하지 않는다.
- Outpost는 비용 10과 동일 건설자의 총 3회 행동 후에만 완공되며 공사 중에는 군사 거점 효과가 없다.
- 군사 거점은 단계에 따라 인접 방어진지를 1/2/3칸 확장하고 아군 방어와 통제 구역을 방향성 있게 강화하지만 수입·생산·영토는 만들지 않는다.
- 공사 취소·건설자 제거·부모 군사 거점 상실과 완공·점령이 원자적으로 처리되고 저장·불러오기 후 진행도가 유지된다.
- 농장 하나는 한 턴에 발전 또는 농지 확장 중 하나만 수행하며 새 농장은 다음 턴부터 확장할 수 있다.
- 농지 수입이 부모 농장의 소유 세력에 정확히 합산된다.
- 농장 점령 시 모든 종속 농지의 귀속이 함께 바뀐다.
- 농지 위에서 유닛 이동·대기·전투가 정상 동작한다.
- 저장·불러오기 후 농지 위치와 부모 관계가 유지된다.
- 관련 테스트와 빌드가 통과한다.

## 후속 목표

다른 거점의 종속 확장, 농지·방어진지 약탈과 복구, 성벽·망루·보급창·포대 분화를 별도 마일스톤으로 검토한다.
