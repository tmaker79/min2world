# Milestone 16: 거점 확장

## 상태

예정

## 목표

농장을 한 타일짜리 아이콘이 아니라 본체와 주변 생산지로 이루어진 거점으로 확장한다. 농장 본체는 헛간과 소규모 작물이 있는 기존 이미지를 사용하고, 인접 타일에 확장한 농지는 넓은 밭 이미지를 한 칸마다 하나씩 표시한다.

이 단계에서는 농장만 확장 대상으로 삼는다. 마을·광산·성의 전용 확장은 후속으로 미룬다.

## 의존

- Milestone 10 거점 개발(`Site.level`, `lastDevelopedTurn` 재사용)
- Milestone 11 성 내정(건설 UI 패턴 재사용)
- Milestone 14 거점 건설(새로 건설한 농장에도 같은 확장 규칙 적용)

## 핵심 개념

- **농장 본체**: `SiteType: 'village'`인 기존 `Site`. 점령·수입·선택의 기준점이다.
- **농지**: 농장 본체에 종속된 인접 타일 확장. 독립 거점이 아니며 별도 소유자를 갖지 않는다.
- **확장 한도**: 농장 본체의 `level`과 같다. 농장 레벨이 오를 때마다 농지를 한 칸 더 확장할 수 있다.
- 농장 본체 타일에는 헛간 중심 이미지를 표시한다.
- 농지 타일에는 넓은 황금색 밭 이미지를 표시한다.
- 농지 한 개가 육각 타일 한 칸을 차지하지만, 원래 지형과 유닛 이동을 대체하지는 않는다.

```text
      [농지]
 [농지][농장][빈칸]
      [농지]
```

## 포함 범위

### 데이터

```ts
type SiteExpansion = {
  siteId: string
  kind: 'farm-field'
  position: Position
}

type GameState = {
  // 기존 필드
  siteExpansions: SiteExpansion[]
}
```

- 농지의 소유권은 `siteId`가 가리키는 농장 본체에서 파생한다. 소유권을 중복 저장하지 않는다.
- 한 타일에는 농지 확장을 하나만 둘 수 있다.
- 농지 타일은 `Tile.siteId`를 사용하지 않는다. 농지는 독립 거점이 아니며 유닛 이동을 막지 않기 때문이다.
- 스키마를 12로 올리고 스키마 11 저장은 `siteExpansions: []`로 마이그레이션한다.
- 저장 검증 시 부모 농장 존재, 인접 관계, 위치 중복, 지도 범위를 확인한다.

### 농장 레벨과 확장 한도

Milestone 10에서는 농장을 1레벨로 고정하지만, 이 마일스톤부터 농장도 1~3레벨로 개발할 수 있다. 기존 `Site.level`과 `lastDevelopedTurn`을 그대로 사용한다.

| 농장 레벨 | 농지 확장 한도 | 다음 레벨 비용 |
| ---: | ---: | ---: |
| 1 | 1칸 | 15 |
| 2 | 2칸 | 25 |
| 3 | 3칸 | — |

- 새 게임의 기존 농장과 Milestone 14에서 새로 건설한 농장은 1레벨로 시작한다.
- 레벨업은 활성 세력이 소유한 농장에서 자원을 즉시 소비해 적용한다.
- 각 농장은 소유 세력의 턴마다 한 번만 레벨업할 수 있다.
- 레벨업만으로 수입이 증가하지는 않는다. 새로 열린 한도에 농지를 실제로 확장해야 수입이 증가한다.
- 점령 시 농장 레벨과 농지는 모두 유지된다.

### 확장 규칙

- 활성 세력이 소유한 농장에서만 확장할 수 있다.
- 농장 본체와 육각 거리 1인 인접 평지에만 농지를 추가할 수 있다.
- 대상 타일에 거점이나 다른 농지가 있으면 확장할 수 없다.
- 건설 시점에 유닛이 있는 타일에는 확장할 수 없다. 완공 후에는 유닛이 농지 위로 이동하거나 머물 수 있다.
- 농장 하나의 농지 수는 현재 농장 레벨을 넘을 수 없다. 1레벨은 1칸, 2레벨은 2칸, 3레벨은 3칸까지 확장한다.
- 농지 한 칸의 확장 비용은 자원 10이다.
- 대기열 없이 즉시 완공하며, 같은 농장을 한 턴에 여러 번 확장할 수 있다. 비용과 최대 칸 수가 자연스러운 제한이 된다.

### 경제

- 농장 본체의 기본 수입 2는 유지한다.
- 농지 한 칸마다 해당 농장 수입이 +1 증가한다.
- 농지 3칸을 모두 확장한 농장의 총수입은 5다.
- 턴 수입 계산은 농장 본체 소유자에게 본체와 종속 농지 수입을 합산한다.

### 점령과 제거

- 적이 농장 본체를 점령하면 종속 농지는 별도 행동 없이 새 소유자에게 귀속된다.
- 농지 타일 위의 유닛은 농장 소유권을 바꾸지 않는다. 점령 판정은 본체 타일에서만 발생한다.
- 농장 본체가 제거되는 후속 기능이 생기면 종속 농지도 함께 제거한다.
- 농지는 개별 약탈·파괴 대상이 아니다. 파괴와 복구는 후속 범위로 둔다.

### 지도 표시와 조작

- 농장 본체는 헛간·작물이 함께 있는 기존 농장 이미지를 사용한다.
- 농지는 현재의 넓고 낮은 황금색 밭 이미지를 타일마다 표시한다.
- 농지 레이어는 지형보다 위, 거점·유닛보다 아래에 렌더링한다.
- 농지 이미지는 육각 경계를 넘지 않으며 지형 그림을 완전히 가리지 않도록 크기를 제한한다.
- 농지 타일을 클릭하면 부모 농장 정보창을 연다.
- 농지 툴팁에 `농지`, 부모 농장 이름, `수입 +1`을 표시한다.
- 소유 세력 깃발은 본체에만 표시하고 농지마다 반복하지 않는다.

### UI

- 소유 농장 정보창에 현재 레벨, 농지 수/레벨별 한도, 다음 레벨 비용, 다음 확장 비용, 총수입을 표시한다.
- 현재 농지 수가 레벨 한도에 도달하면 `농장 개발` 버튼으로 다음 레벨을 먼저 올리도록 안내한다.
- `농지 확장`을 선택하면 건설 가능한 인접 평지를 강조한다.
- 강조된 타일을 선택하면 비용과 수입 증가를 확인한 뒤 확장한다.
- 자원 부족, 현재 레벨 한도 도달, 3레벨·3칸 최대 도달, 유효한 인접 평지 없음 상태를 구분해 안내한다.

### AI

- AI는 모든 군사 행동을 마친 뒤 농장 개발과 농지 확장을 판단한다.
- 농지가 현재 레벨 한도에 도달했고 다음 레벨 개발 후에도 자원 10을 남길 수 있으면 세력 턴당 농장 하나를 개발한다.
- 확장 후에도 자원 10을 남길 수 있을 때만 세력 턴당 농지 하나를 확장한다.
- 후보 농장은 현재 농지 수 오름차순, 농장 ID 오름차순으로 선택한다.
- 후보 타일은 `r`, `q` 오름차순으로 선택해 결정론을 유지한다.

## 구현 순서

1. 농장 본체 이미지를 복원하고 넓은 밭 이미지를 별도 농지 에셋으로 분리한다.
2. `SiteExpansion` 데이터와 스키마 12 마이그레이션·검증을 추가한다.
3. 농장 레벨업과 레벨별 확장 한도 규칙을 추가한다.
4. 확장 가능 위치와 수입 계산 규칙, reducer 액션을 구현한다.
5. 맵 농지 레이어와 농장 정보창의 개발·확장 조작을 연결한다.
6. AI 개발·확장 정책과 저장·점령·UI 테스트를 추가한다.

## 제외 범위

- 마을 주거지, 광산 채굴장, 성 외곽 시설 확장
- 농지 개별 점령·파괴·약탈·복구
- 작물 종류, 계절, 식량 자원 분리
- 농지 전용 이동 비용이나 전투 보정
- 농장 본체에서 두 칸 이상 떨어지는 연결형 확장

## 완료 조건

- 농장 본체와 농지가 서로 다른 이미지로 명확히 구분된다.
- 플레이어와 AI가 농장 레벨을 올리고, 현재 레벨만큼 인접 평지에 농지를 확장할 수 있다.
- 농지 수입이 부모 농장의 소유 세력에 정확히 합산된다.
- 농장 점령 시 모든 종속 농지의 귀속이 함께 바뀐다.
- 농지 위에서 유닛 이동·대기·전투가 정상 동작한다.
- 저장·불러오기 후 농지 위치와 부모 관계가 유지된다.
- 관련 테스트와 빌드가 통과한다.

## 후속 목표

마을 주거지·광산 채굴장·성 외곽 시설 확장, 농지 약탈과 복구를 별도 마일스톤으로 검토한다.
