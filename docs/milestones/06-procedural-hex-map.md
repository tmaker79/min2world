# Milestone 06: 무작위 육각 지도와 seed

## 상태

예정

## 목표

현재 10×10 사각형 고정 지도를 seed로 재현할 수 있는 육각형 무작위 지도로 전환하고 지형과 거점 종류를 확장한다.

## 포함 범위

### 육각형 지도

- 사각 좌표를 육각 좌표 체계로 교체
- 육각형 6방향 이동, 인접, 공격 범위와 통제 구역
- 육각 타일 렌더링과 마우스·키보드 상호작용
- 기존 이동·경로 탐색·AI의 육각 좌표 대응

### 무작위 생성과 seed

- 같은 seed가 항상 같은 지도와 시작 배치를 생성하는 결정론적 생성기
- 새 게임에서 seed 입력, 자동 생성과 현재 seed 확인
- 양 세력이 이동 가능한 경로로 연결되는 지도 검증
- 시작 위치 주변의 최소 이동 가능 영역과 세력 간 균형 검사
- 저장 데이터에 seed와 생성 규칙 버전 포함

### 지형 확장

- 기존: 평지, 산, 물
- 추가: 언덕, 길, 숲, 초원, 평원
- 지형별 이동 비용, 통행 여부와 전투 효과
- 길이 다른 지형의 이동 비용을 완화하는 연결 규칙

### 거점 확장

- 기존 성
- 추가 도시, 마을, 광산
- 거점 종류별 자원 수입과 생산 가능 여부
- 무작위 지도에서 거점 수, 간격, 소유권과 시작 거점 배치

## 구현 순서

1. 육각 좌표와 6방향 규칙을 순수 TypeScript로 구현한다.
2. 기존 고정 지도를 육각 렌더링과 이동·전투·AI에 연결한다.
3. seed 기반 지도 생성기와 재현성 테스트를 추가한다.
4. 지형 5종과 거점 3종을 추가하고 생성 규칙에 반영한다.
5. 저장 스키마를 올리고 이전 사각 지도 저장의 호환 정책을 적용한다.

## 호환성 주의

육각 좌표 전환은 좌표, 타일, 이동 경로와 저장 데이터 구조를 모두 변경한다. Milestone 04 저장 데이터에는 스키마 버전이 있으므로, Milestone 06에서는 지원 가능한 데이터만 명시적으로 변환하고 나머지는 안전하게 거부한다.

## 제외 범위

- 무한 지도와 월드 스트리밍
- 지도 편집기
- 온라인 seed 공유 서비스
- 3D 지형과 PixiJS 렌더러 전환

## 완료 조건

- 같은 seed로 동일한 육각 지도, 지형, 거점과 시작 배치를 재현할 수 있다.
- 생성된 지도에서 양 세력이 고립되지 않고 한 판을 끝낼 수 있다.
- 이동·전투·통제 구역·AI·저장이 육각 좌표에서 정상 동작한다.
