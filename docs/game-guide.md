# min2world 게임 가이드

`min2world`는 육각 지도에서 부대를 이동하고 전투하며 상대 수도를 점령하는 웹 턴제 전략 시뮬레이션 게임이다.

현재 공개 메인은 핵심 전투·생산·점령에 집중한 **2인용 빠른대전**이며, 전체모드는 발전·건설·정착 등 확장 규칙을 제공한다.

- [빠른대전 플레이](https://min2world.dev)
- [전체모드(beta)](https://beta.min2world.dev)
- [빠른대전 조작 방법](../README.md#빠른대전-조작-방법)

## 게임 모드와 맵 크기

빠른대전은 2세력·15 × 11 균형 지도로 즉시 시작한다. 전체모드에서는 시작 화면에서 지도 크기·지도 종류·플레이할 세력을 선택할 수 있다.

| 구분 | 크기 | 비고 |
| --- | --- | --- |
| 2인용 | 15 × 11 | 2세력 듀얼 전용 |
| 초소형 | 21 × 15 | 현재 2세력 지원 |
| 소형 | 29 × 21 | 현재 2세력 지원 |
| 중형 | 41 × 29 | 현재 2세력 지원 |

두 모드 모두 세력 수는 현재 2개로 고정되어 있다.

2인용 15 × 11 지도는 화면 중앙 열이 강으로 막혀 있으며, 위에서 네 번째와 여덟 번째 행의 다리 두 곳으로만 강을 건널 수 있다. 다리와 좌우 접근 타일에는 거점과 시작 유닛이 배치되지 않는다.

새 지도에는 세력별 중립 농장·광산·대장간이 하나씩 배치되며, 중립 마을과 전초기지는 생성하지 않는다.

## 전체모드 추가 기능

전체모드는 빠른대전의 핵심 규칙에 다음 기능을 더한 확장 모드다.

- 시작 화면에서 맵 크기·지도 종류·플레이할 세력을 선택한다.
- 거점의 `발전` 탭에서 다음 단계와 효과를 확인하고 거점을 발전시킨다.
- 도시에서는 군사 유닛과 개척자·건설자를 모두 생산한다. `건설` 탭에서는 곡창·시장·성벽·병영·선술집·신전·도서관을 건설하며, 도시당 건설 대기열은 하나다. 건설을 취소해도 자원은 환불되지 않는다.
- 개척자는 현재 칸에 마을을 세우면서 소모된다. 건설자는 전초기지·농장·광산·대장간을 건설한 뒤에도 유지된다.
- 빈 타일이나 적 유닛을 좌클릭하면 해당 정보를 사이드바에 고정할 수 있다.
- AI는 부대 행동을 마친 뒤 경제 상황에 따라 거점 발전·도시 내정 건설·부대 생산을 판단한다.

건설자가 세운 농장·광산·대장간은 통행 가능한 육지 거리 3 이내에서 가장 가까운 아군 소도시·도시의 지원을 받는다. 소도시는 2개, 도시는 4개까지 지원하며, 맵에서 생성된 중립 생산 거점은 점령 후에도 이 한도에서 제외된다. 한도를 초과해도 기존 생산 거점은 유지되고 새 건설만 차단된다.

## 주요 규칙

- 평지·다리·오아시스의 이동 비용은 1이고, 사막·사막 언덕·툰드라·툰드라 숲·언덕·숲은 2다. 산·툰드라 산·물은 통과할 수 없다.
- 언덕·사막 언덕·숲·툰드라 숲에서는 전투력 보정 +3을 받는다.
- 보병은 표준 근접 병종, 기병은 고속 공격 병종, 궁병은 사거리 2의 원거리 병종, 창병은 대기병 병종이다. 공격하면 남은 이동력을 모두 사용한다.
- 적 유닛과 소유된 군사 거점은 주변에 통제 구역을 만든다. 통제 구역에 진입하면 이동이 멈추며, 이동 경로는 통제 구역을 관통할 수 없다.
- 군사 거점의 HP가 0이 되면 공격 세력이 점령하고 최대 HP의 50%를 회복한다. `전초기지 → 요새 → 성채`는 현재 HP 비율을 유지하며 발전하고, `소도시 → 도시`는 최대 HP로 시작한다.
- 턴 종료 시 자원은 `max(0, 현재 자원 + 수입 - 유지비)`로 정산된다. 생산·발전·건설 후에도 다음 적자분을 감당할 자원을 남겨야 한다.

### 병종별 유지비

| 병종 | 유지비/턴 |
| --- | ---: |
| 보병 | 1 |
| 창병 | 1 |
| 궁병 | 1 |
| 기병 | 2 |
| 개척자 | 1 |
| 건설자 | 1 |

### 요새화 거점

| 요새화 거점 | 최대 HP | 방어력 |
| --- | ---: | ---: |
| 전초기지 | 50 | 35 |
| 요새 | 75 | 42 |
| 성채 | 100 | 50 |
| 도시 | 120 | 55 |

### 거점 수입과 생산

| 거점 | 수입 | 생산 |
| --- | ---: | --- |
| 전초기지 / 요새 / 성채 | 0 / 0 / 0 | 불가 |
| 마을 / 소도시 / 도시 | 3 / 6 / 9 | 도시에서 군사 유닛 생산, 전체모드는 민간 유닛도 생산 |
| 농장 Lv.1~3 | 2 / 3 / 4 | 불가 |
| 광산 Lv.1~3 | 3 / 4 / 5 | 불가 |
| 대장간 Lv.1~3 | 2 / 3 / 4 | 불가, 도시의 군사 유닛 생산비 할인 |

## 저장 데이터

- 게임은 현재 컴퓨터와 브라우저의 `localStorage`에 모드별 단일 슬롯으로 저장된다. 빠른대전은 기존 전체모드 저장을 덮어쓰지 않는다.
- 플레이어 턴에서만 저장할 수 있으며 AI 행동이나 전투 중에는 저장·불러오기가 잠긴다.
- 앱을 다시 열어도 저장은 자동 적용되지 않으며 `불러오기`를 직접 선택해야 한다.
- 다른 컴퓨터·브라우저·배포 주소와 동기화되지 않는다.
- 브라우저 사이트 데이터를 삭제하거나 시크릿 모드를 종료하면 저장이 사라질 수 있다.

저장 스키마와 마이그레이션 정책은 [개발 계획의 저장 정책](development-plan.md#9-저장-정책)을 참고한다.
