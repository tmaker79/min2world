# min2world

React와 TypeScript를 학습하며 만드는 싱글 플레이 웹 턴제 전략 시뮬레이션 게임입니다.

시작 화면에서 맵 크기·세력 수·내 세력을 고른 뒤, seed로 재현되는 육각 지도에서 부대를 이동하고 전투하며 상대 수도를 점령해 승리합니다. 성에서 보병·기병·궁병·창병을 생산할 수 있고, AI도 같은 경제·생산·전투 규칙으로 행동합니다. 플레이어 턴은 브라우저에 저장해 이어서 플레이할 수 있습니다.

## 개발 환경

- Node.js 22.12 이상
- npm

## 실행

```bash
npm install
npm run dev
```

개발 서버가 출력한 로컬 주소를 브라우저에서 엽니다.

## 검증

```bash
npm test
npm run lint
npm run build
```

테스트를 수정하면서 계속 실행하려면 `npm run test:watch`를 사용합니다.

## 맵 크기

| 구분 | 크기 | 비고 |
| --- | --- | --- |
| 2인용 | 15 × 11 | 2세력 듀얼 전용 |
| 초소형 | 21 × 15 | 현재 2세력 지원 |
| 소형 | 29 × 21 | 현재 2세력 지원 |
| 중형 | 41 × 29 | 현재 2세력 지원 |

세력 수는 현재 2개로 고정되어 있습니다.

## 조작 방법

1. 시작 화면에서 맵 크기, 세력 수, 내 세력, seed를 정한 뒤 게임을 시작합니다.
2. 내 세력 유닛을 좌클릭해 선택합니다.
3. 금색으로 표시된 이동 가능 칸을 **우클릭**해 이동합니다. 이동 비용만큼 이동력이 차감되며, 남은 이동력으로 계속 이동할 수 있습니다.
4. 붉은 표시가 된 적을 좌클릭해 공격합니다. 궁병은 육각 거리 2까지 공격하며, 돌진·피해·반격과 유닛 제거 결과가 순서대로 표시됩니다.
5. 사선으로 표시된 적 통제 구역에 남은 이동력을 가지고 진입하면 추가 이동은 멈추지만 인접한 적은 공격할 수 있습니다. 진입까지 이동력을 모두 사용했다면 공격할 수 없습니다.
6. 지형·거점 칸에 마우스를 올리면 툴팁으로 지형 정보가 표시됩니다. 유닛 칸은 유닛 요약 툴팁이 우선합니다.
7. 내 성을 좌클릭하면 성 정보창이 열립니다. 위부터 생산 목록(생산 선택 시) → 생산/건설 메뉴 → 성 정보가 표시됩니다. 건설은 아직 미구현입니다.
8. 유닛을 선택하면 성 정보창과 같은 스타일의 부대 정보창이 열립니다.
9. 플레이어 유닛의 행동을 마치면 `턴 종료`를 선택하거나 `Enter`를 누릅니다. 생산 배치 중에는 `Esc`로 취소합니다.
10. 지도는 드래그로 팬하고, 마우스 휠로 확대·축소할 수 있습니다. 미니맵으로도 시점을 옮길 수 있습니다.
11. AI는 사거리 안의 플레이어 유닛을 우선 공격하고, 공격할 수 없으면 목표를 향해 이동합니다. 모든 부대가 행동한 뒤 자원을 쓸 수 있으면 생산합니다.
12. 상대 세력의 모든 수도(성)를 점령하면 승리하고, 내 수도를 잃으면 패배합니다.
13. 상단 `새 게임`에서 seed를 입력하거나 `무작위 지도`로 새 판을 시작합니다. `저장`·`범례`·`도움말`도 같은 상단 메뉴에서 엽니다.

평지 이동 비용은 1, 언덕과 숲은 2입니다. 산과 물은 통과할 수 없습니다. 언덕·숲은 전투력 보정 +3입니다. 적 유닛의 육각 인접 6칸은 통제 구역이며 이동 경로가 이를 관통할 수 없습니다. 보병은 표준 근접 병종, 기병은 고속 공격 병종, 궁병은 사거리 2의 원거리 병종, 창병은 대기병 보너스를 가진 병종입니다. 공격하면 해당 유닛의 남은 이동력을 모두 사용합니다. 세력 턴을 종료하면 현재 소유 거점의 수입이 지급됩니다.

| 거점 | 수입 | 생산 |
| --- | ---: | --- |
| 성 | 5 | 가능 |
| 마을 | 4 | 불가 |
| 농장 | 2 | 불가 |
| 광산 | 3 | 불가 |

## 저장 데이터

- 게임은 현재 컴퓨터와 브라우저의 `localStorage`에 단일 슬롯으로 저장됩니다.
- 현재 스키마는 7입니다. 스키마 6 저장은 `f1`/`f2`로 마이그레이션해 불러올 수 있고, 사각 지도 기반 스키마 4·5는 불러오지 않습니다.
- 플레이어 턴에서만 저장할 수 있으며 AI 행동이나 전투 중에는 저장·불러오기가 잠깁니다.
- 앱을 다시 열어도 저장은 자동 적용되지 않으며 `불러오기`를 직접 선택해야 합니다.
- 다른 컴퓨터·브라우저·배포 주소와 동기화되지 않습니다.
- 브라우저 사이트 데이터를 삭제하거나 시크릿 모드를 종료하면 저장이 사라질 수 있습니다.
