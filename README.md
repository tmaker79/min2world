# min2world

React와 TypeScript를 학습하며 만드는 싱글 플레이 웹 턴제 전략 시뮬레이션 게임입니다.

현재 구현에서는 10×10 지도에서 플레이어 유닛을 이동하고, 적과 전투하며, 도시를 점령해 승리할 수 있습니다. 도시 수입으로 보병·기병·궁병·창병을 생산할 수 있고 규칙 기반 AI도 같은 경제·생산·전투 규칙으로 행동합니다. 플레이어 턴은 브라우저에 저장해 이어서 플레이할 수 있습니다.

## 개발 환경

- Node.js 22.12 이상
- npm

## 실행

```bash
npm install
npm run dev
```

개발 서버가 출력한 로컬 주소를 브라우저에서 엽니다.

## 검증

```bash
npm test
npm run lint
npm run build
```

테스트를 수정하면서 계속 실행하려면 `npm run test:watch`를 사용합니다.

## 조작 방법

1. 푸른 유닛을 선택합니다.
2. 금색 테두리로 표시된 타일을 선택해 이동합니다. 이동 비용만큼 이동력이 차감되며, 남은 이동력으로 계속 이동할 수 있습니다.
3. 붉은 테두리로 표시된 적을 선택해 공격합니다. 궁병은 맨해튼 거리 2까지 공격하며, 돌진, 피해, 반격과 유닛 제거 결과가 순서대로 표시됩니다.
4. 사선으로 표시된 적 통제 구역에 남은 이동력을 가지고 진입하면 추가 이동은 멈추지만 인접한 적은 공격할 수 있습니다. 진입까지 이동력을 모두 사용했다면 공격할 수 없습니다.
5. 행동 완료된 유닛도 다시 선택해 체력과 능력치를 확인할 수 있습니다.
6. 플레이어 유닛의 행동을 마치면 `턴 종료`를 선택하거나 `Enter`를 누릅니다.
7. AI는 인접한 플레이어 유닛을 우선 공격하고, 공격할 수 없으면 플레이어 도시를 향해 이동합니다.
8. 붉은 요새를 점령하면 승리하고, AI가 푸른 성채를 점령하면 패배합니다. 결과 화면의 `새 게임`으로 다시 시작할 수 있습니다.
9. 우측 `저장 관리`에서 게임을 저장하거나 불러오고 저장 데이터를 삭제할 수 있습니다.
10. 우측 `부대 생산`에서 도시와 병종을 선택한 뒤 청록색 타일을 눌러 생산합니다. 도시는 라운드당 한 번 생산할 수 있으며 새 부대는 다음 자기 세력 턴부터 행동합니다.

평지는 이동력 1, 산은 이동력 2를 사용하고 물은 통과할 수 없습니다. 적 유닛의 상하좌우 인접 타일은 통제 구역이며 이동 경로가 이를 관통할 수 없습니다. 보병은 표준 근접 병종, 기병은 고속 공격 병종, 궁병은 사거리 2의 원거리 병종, 창병은 높은 반격력과 대기병 피해 보너스를 가진 병종입니다. 공격하면 해당 유닛의 남은 이동력을 모두 사용합니다. 세력 턴을 종료하면 현재 소유 도시의 수입이 지급됩니다.

## 저장 데이터

- 게임은 현재 컴퓨터와 브라우저의 `localStorage`에 단일 슬롯으로 저장됩니다.
- 이전 스키마 4 저장은 불러올 때 현재 스키마 5로 자동 변환됩니다.
- 플레이어 턴에서만 저장할 수 있으며 AI 행동이나 전투 중에는 저장·불러오기가 잠깁니다.
- 앱을 다시 열어도 저장은 자동 적용되지 않으며 `불러오기`를 직접 선택해야 합니다.
- 다른 컴퓨터·브라우저·배포 주소와 동기화되지 않습니다.
- 브라우저 사이트 데이터를 삭제하거나 시크릿 모드를 종료하면 저장이 사라질 수 있습니다.
