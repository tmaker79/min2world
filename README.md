# min2world

React와 TypeScript를 학습하며 만드는 싱글 플레이 웹 턴제 전략 시뮬레이션 게임입니다.

현재 구현에서는 10×10 지도에서 플레이어 유닛을 선택하고, 지형별 이동 비용에 따라 표시된 타일로 이동한 뒤 턴을 종료할 수 있습니다. 적 세력은 지도에 표시되지만 아직 행동하지 않습니다.

## 개발 환경

- Node.js 22.12 이상
- npm

## 실행

```bash
npm install
npm run dev
```

개발 서버가 출력한 로컬 주소를 브라우저에서 엽니다.

## 검증

```bash
npm test
npm run lint
npm run build
```

테스트를 수정하면서 계속 실행하려면 `npm run test:watch`를 사용합니다.

## 조작 방법

1. 푸른 유닛을 선택합니다.
2. 밝은 테두리로 표시된 이동 가능 타일을 선택합니다.
3. 플레이어 유닛의 행동을 마치면 `턴 종료`를 선택합니다.

평지는 이동력 1, 산은 이동력 2를 사용하고 물은 통과할 수 없습니다. 보병의 이동력은 2, 기병의 이동력은 3입니다.

전체 개발 목표와 다음 단계는 [개발 계획](docs/min2world.md)을 참고하세요.
