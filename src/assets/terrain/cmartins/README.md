# Hex Tiles: Fantasy 파생 지형 타일

이 디렉터리의 모든 파일은 [cmartins.art](https://cmartins.itch.io/)의
[Hex Tiles: Fantasy](https://cmartins.itch.io/hex-tiles-fantasy)를 기반으로
편집·변형한 지형 에셋이며
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)으로
제공됩니다.

변경 사항에는 게임용 이미지 편집, 크기 조정 및 변형이 포함됩니다.
`tundra-mountain-tile.png`는 원본 에셋의 시각적 방향에 맞춰 생성했으며,
이 프로젝트에서는 동일한 파생 에셋 모음에 포함합니다.

전체 고지는 프로젝트 루트의
[`THIRD_PARTY_NOTICES.md`](../../../../THIRD_PARTY_NOTICES.md)를
